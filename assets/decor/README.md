# 背景のパーツ画像を置く場所

ここに `part-01.png` のような**背景が透明な PNG** を置くと、
水槽の背景がその画像で組み立てられる。

**空のままでも動く。** 画像が1枚も無ければ、図形で描く方式に切り替わる
（`aquariumScene.ts` の `useParts`）。

## 入れ方

1枚にまとまった一覧画像で受け取ったら、切り出してからここへ置く。

```sh
python3 tools/split-parts.py <一覧画像のパス> assets/decor
```

白い背景を透明にし、つながっている塊ごとに分けて、余白を詰めて保存する。

## いま入っているもの

`tools/make-parts.py` で生成した20個（岩6・枝サンゴ4・脳サンゴ4・海藻3・小石3）。
**外から絵をもらったら、それで置き換えてよい。** 作り直すときは

```sh
python3 tools/make-parts.py assets/decor
```

同じ種を使うので、何度動かしても同じ絵が出る。

## 作り方

`docs/背景パーツの作り方.md` に、画像生成のプロンプトと出力の仕様がある。
**落ち影は描かせないこと**（接地の影はアプリ側で付けるので二重になる）。
