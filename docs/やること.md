## 水族館を直す（2026-08-24 に測った。2 は直した／1 は戻した）

**恐竜テーマを作っている間に、水族館側が置いていかれている。**
下は実測した順に並べてある。数字はすべて 1920×1080・この開発環境（**GPUなし**）。
**会場のWindows機ではもっと出るはずなので、ここの数字は下限として見ること。**

### 1. 速さ（いちばん大きい）★

絵24枚で **19fps**。50枚だと **16fps**。層ごとに外して測った結果:

| 外したもの | fps | そのぶんの重さ |
|---|---|---|
| （そのまま） | 19 | — |
| **揺らぎ模様 2枚** | **42** | **約29ms** ← 断然これ |
| 　うち細かいほう1枚だけ | 26 | 約14ms |
| 動かない層（水・砂・パーツ・暗がり） | 25 | 約13ms |
| 光の筋 | 21 | 約5ms |
| 泡 | 20 | 約1ms |
| 背景を全部止める（強さ0） | 60 | — |

**やった手**:

- ~~動かない層を1枚に焼く~~ → **入れた**（2026-08-24・F-339）。
  絵24枚で **8.6〜8.9 → 11.0fps（+25%）**、背景だけで 12.2 → 14.0fps。
  見た目は変わらない（海底の帯の画素差は平均 0.3・最大 13）

**まだ手を付けていない手**:

- 光の筋と泡は後回し（合わせて6ms）
- 揺らぎ模様は 1-b のとおり保留（焼くと背景がループして見える）

> **注意**: この環境はソフトウェア描画。会場PCで先に測ってから決めてもよい（T-3）。

### 1-b. 揺らぎ模様を軽くしようとした結果（2026-08-24・**やってみて戻した**）

上の「やること 1」を実際に試した。**採用できるものが無かったので、全部戻してある**
（`drawCaustics.ts` / `caustics.ts` は元のまま。差分ゼロ）。

測り直した数字（絵24枚・1920×1080・**別の日の同じ環境**。上の表とは絶対値が違う。
コンテナを作り直すと同じビルドでも 19fps → 15fps に変わったため、
**上の表と下の表を直接くらべないこと**）:

| 試したこと | fps |
|---|---|
| （そのまま） | 15 |
| 2枚を1枚にまとめる | 15（**変わらない**） |
| 加算合成をやめる | 17 |
| 拡大時のぼかしを切る | 18 |
| 計算する面を半分の広さに | 16 |
| 更新を毎秒12回に落とす | 18 |
| **起動時に24コマ焼いておく（毎フレームの転送ゼロ）** | **23** |
| 揺らぎ模様を消す | 35 |
| 背景を全部止める（強さ0） | 60 |

分かったこと: 重いのは**計算ではなく、CPUで作った画像をGPUへ毎フレーム渡すこと**
（`putImageData`）。だから「面を小さくする」「更新回数を減らす」ではほとんど減らない。
**焼いておく以外に大きく効く手が無い。**

焼かなかった理由: 揺らぎ模様は**わざと割り切れない周期**を重ねて作ってある
（同じ形が戻ってこないようにするため）。焼いたコマを繰り返すと、
**数秒ごとに同じ模様が戻る**のが分かる。会場では絵よりゆっくりした背景なので、
繰り返しは目につきやすい。**15 → 23fps と引き換えに背景がループして見える**のは、
実機の数字を見る前に払う代償として大きすぎる。

→ **T-3（会場PCでの実測）待ちにする。** 実機で 30fps を超えるなら、この作業は要らない。
超えないなら、焼くコマ数を増やす（24 → 120コマ、記憶は 120×640×360×4 ≒ 110MB）か、
模様そのものを繰り返してよい形に作り直すかを決める。

### 2. ~~ウミガメが画面の下に溜まる~~ → **直した**（2026-08-24・F-338）

原因は「上下の動きがS字の波しか無かった」こと。波は今いる高さを中心に
画面の高さの 10〜13% を往復するだけなので、**生まれた高さから一生離れられない**。
初期の高さの問題ではなかった（そちらは散らばっていた）。

150秒で1往復する、ゆっくりした上下の動きを足した（`behaviour.ts` の `wanderY`）。
5分の実測、画面を上から5等分した滞在時間の割合:

| | 一番上 | 上 | 真ん中 | 下 | 一番下 |
|---|---|---|---|---|---|
| ウミガメ（直す前） | 0% | 3% | 25% | 24% | **49%** |
| ウミガメ（直したあと） | 17% | 15% | 24% | 20% | 23% |
| タコ（直したあと） | 21% | 20% | 18% | 23% | 19% |

### 3. ~~台紙の見分けが際どい~~ → **直した**（2026-08-24・F-218/F-219）

**「クラゲを縦長にすれば離れる」という見立ては外れだった。**
そのとおり作り直しても、2位との差は +0.00 → +0.01 しか動かない。
触手を伸ばすと相手との重なりも自分との重なりも同じだけ落ちるため（R-042）。

効いたのは照合側で、**紙の置き方のずれ（±8°・4°刻み）も試す**ようにしたこと。
それまで 90度ずつしか試しておらず、紙が数度傾くと細い形が升目から外れていた。

| | 見分けの試験 | いちばん際どい組の差 |
|---|---|---|
| 水族館6種（前） | 48/48 | +0.00 |
| 水族館6種（後） | 48/48 | **+0.20** |
| 恐竜5種（前） | 39/40 | -0.05（プテラノドン → ブロントサウルス） |
| 恐竜5種（後） | **40/40** | **+0.22** |

あわせて、**台紙11枚すべてを長辺 2400px にした**（F-219・印刷用）。
クラゲも 2:1 の縦長にしてある（重なり 0.55 → 0.44）。

残っているのは**実物の写真での測り直し**（T-1）。ここまでは全部、
台紙そのものを傾けて測った数字であって、**塗った紙の写真ではない**。
