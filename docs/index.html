お絵かき水族館

塗った紙をスキャンすると、その絵が大画面で動き出します。

Windows 版をダウンロード 押すとすぐ落ちてきます（インストーラ・約 100MB）

落とせないときは zip 版。インストールできない PC には 持ち運び版。

入れかた（3つだけ）

  1. 上のボタンを押して、落ちてきた PaintingsAquarium-Setup.exe をダブルクリックします。
  2. 青い画面が出ます。これは必ず出ます。 左下の小さな文字「詳細情報」を押すと、「実行」が現れます。
    WindowsによってPCが保護されました
    Microsoft Defender SmartScreen は認識されないアプリの起動を停止しました。
    詳細情報← ここを押す
    実行しない

    ↑ 実機の写真ではなく、出る画面を描いたものです。文言は版によって多少違います。

    これは「作った人の身元を証明する電子署名」を付けていないために出るもので、 中身が危ないという意味ではありません。署名には毎年2〜5万円かかるため、 会場PC 1台のために付けていません。

  3. あとは画面のとおり進めば終わりです。起動したら、設定を1回だけしてください （取り込みフォルダとテーマ）。やり方は下のマニュアルにあります。

USB に入れてから開くと、青い画面そのものが出ません。 別の PC で落として USB にコピーし、会場PCではそこから開く ―― これが一番確実です。 会場PCが借り物で設定を変えられないときも、この方法なら通ります。

ダウンロードの段階で止まるとき

ブラウザが「安全でない可能性があるアプリをブロックしました」と出して、 exe を落とさせないことがあります。これは署名とは別の、 「インストーラの形をしていて、まだ使っている人が少ない」という判定です。

そのときは zip を落としてください。中身はまったく同じです。 ただの書庫なので、この判定に引っかかりません。

PaintingsAquarium.zip をダウンロード

落としたら 右クリック →「すべて展開」。 （「ここに展開」だとファイルが 75 個ばらけます。） 展開したフォルダの中の PaintingsAquarium.exe を開けば動きます。 インストールは要りません。

3つのファイルの使い分け

  • PaintingsAquarium-Setup.exe
    会場PCに入れて使う。落とせるならこれが一番楽です
  • PaintingsAquarium.zip
    exe が落とせないとき。中身は同じ。展開して開くだけ
  • PaintingsAquarium-portable.exe
    インストールできない PC 用。USB から直接動きます

3つとも 最新版の置き場 にあります。 ファイル名は毎回同じで、いま入っている版はアプリの設定画面（S キー）に出ます。

いっしょに要るもの

  • お絵かき水族館-台紙.pdf
    水族館（6ページ）
  • お絵描き動物園-台紙.pdf
    動物園（ぞう・ライオン・キリン・さる・パンダ・しまうま）
  • お絵かきダイナソー-台紙.pdf
    恐竜（5ページ）
  • お絵かきハロウィン-台紙.pdf
    ハロウィン（5ページ・10月むけ）
  • お絵かき-現場マニュアル.pdf
    当日の進め方。スキャナの設定と、貼り紙にできるページつき

台紙は A4・よこ・等倍で刷ってください。 「用紙に合わせる」は切ってください（縮むと取り込みの結果が変わります）。両面にしないでください。

よくある詰まりどころ

入れ替えても絵が消えませんか

消えません。 絵と設定はアプリとは別の場所に保存してあります。 上書きインストールして大丈夫です。

インターネットは要りますか

要りません。 落としたあとは、会場で一度もつながなくても動きます。 絵が外に出ることもありません。

次からの更新は

アプリの設定画面（S キー）→「更新を確認」→「いま入れ替えて再起動する」。 0.1.73 以前を使っている場合だけ、1回手で入れ替えてください （それより前は入れ替えが Windows に止められて、何も起きません）。

うまくいかないときは、画面に出た言葉をそのままお知らせください。 言葉で止めている仕組みが分かります。
