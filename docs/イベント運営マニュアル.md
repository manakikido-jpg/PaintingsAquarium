# イベント運営マニュアル

会期を1回まわすための手順。**発注から、当日、片付けまで。**

- 最終更新: 2026-09-12
- 関連: `docs/リハーサル手順.md`（新しい会場で初めてやる前に）／
  `docs/配布手順.md`（アプリの入れ方）／`docs/台紙の作り方.md`（台紙を作り直すとき）

---

## 0. 誰が何をするか

**このアプリの核心は「会場スタッフのアプリ操作を0回にする」こと。**
スタッフがやるのは**紙をスキャナに置くこと**だけで、アプリには触りません。

| | やること | 回数 |
|---|---|---|
| **運営者**（1人） | 発注・設営・設定・片付け | 会期の前後に1回ずつ |
| **会場スタッフ** | 紙を配る／描けた紙をスキャンする | スキャン 30〜100回／日 |
| **会場スタッフ** | アプリの操作 | **0回** |

スタッフに新しい操作を増やす話が出たら、まずこの表に戻ってください。

## 1. 2週間前 — 台紙を発注する

### 発注する PDF

| ファイル | 中身 |
|---|---|
| `docs/お絵かき水族館-台紙.pdf` | 水族館 6種 |
| `docs/お絵かきダイナソー-台紙.pdf` | 恐竜 5種 |
| `docs/お絵かき台紙-全11枚.pdf` | 全部（下見・試し刷り用） |

**会期で使うのは片方のテーマだけ**なので、ふだんはテーマごとの PDF を発注します。
ログイン不要で落とせるリンクは、アプリの配布ページにも置いてあります。

### 印刷会社に伝える仕様

| 項目 | 指定 | 外すとどうなる |
|---|---|---|
| 用紙サイズ | **A4** | — |
| 向き | **よこ** | 全種そろえてあります |
| 面付け | **片面** | 裏写りすると切り抜きが荒れます |
| 倍率 | **等倍**（縮小・拡大なし） | 大きさが変わると台紙の見分けが不安定になります |
| フチなし | **不要** | — |
| 紙の色 | **白**（色付き・再生紙のクリーム色は避ける） | 紙の色を基準に切り抜くので、色付きだと絵まで消えることがあります |
| 紙質 | **マット系の普通紙・上質紙**（**コート紙・光沢紙は不可**） | 下の「なぜ光沢紙が駄目か」 |
| 厚さ | 上質 90kg 前後（ふつうのコピー用紙〜少し厚め） | 薄すぎるとクレヨンで破れます |

> **なぜ光沢紙が駄目か**
>
> 2つあります。**クレヨンが乗りません。** そして使っているスキャナ
> （CZUR Shine Ultra Pro）は**上からライトを当てて撮る**方式なので、
> 光沢紙だと**ライトが紙に反射して白く飛びます**。
> 飛んだところは「紙」と判定されて、絵ごと消えます。

### 枚数の決め方

前回の実績は **イオン久御山店 420人/2日**、**イオン大日店 210人/2日** でした。
**参加人数＝台紙の枚数**と考えて、そこに**2割ほど上乗せ**します
（描き直し・予備・スタッフの試し用）。

種類は**均等で発注して構いません**。人気は会場で偏りますが、
偏りは事前には読めません。**足りなくなりやすい種類を1〜2種だけ多め**にする、
くらいで十分です。

## 2. 前日 — アプリとスキャナを整える

### 2-1. アプリを最新にする

設定画面（`S` キー）→「更新を確認」→「いま入れ替えて再起動する」。
**絵と設定は消えません。**

うまくいかないときは配布ページから落として上書きしてください。
👉 https://github.com/manakikido-jpg/PaintingsAquarium/releases/tag/latest

**必ず前日までにやること。** 当日の朝に更新すると、
失敗したときに直す時間がありません。

### 2-2. 前のイベントの絵を片付ける

**ここをやらないと、前回の絵が混ざったまま始まります。**
手順は §5「イベントを終える」にあります。**前回の終わりにやってあれば不要**です。

### 2-3. スキャナ（CZUR Shine Ultra Pro）の設定

**アプリの操作は0回ですが、スキャナ側の設定は最初に1回だけ要ります。**
ここを外すと全部止まります。

| 設定 | こうする | 外すとどうなる |
|---|---|---|
| **保存形式** | **JPG** | **PDF は読めません。** 書類用スキャナは既定が PDF のことが多い。1枚も泳ぎません |
| **保存先フォルダ** | アプリの**取り込みフォルダ** | 違うと、スタッフの操作が「毎回コピーする」に増えます |
| **解像度** | **150〜300dpi** | 600dpi は要りません（実測で150も300も取り込み約2.9秒） |
| **ファイル名** | **通し番号。リセットしない** | 毎回 `img001` に戻る設定だと、**二重取り込みとみなして黙って捨てます**。絵が静かに消えます |
| **トップLED** | **点ける** | 影が濃いと、紙の一部が「紙ではない」と判定されて取り込みを断ります |
| **フットペダル** | **使う** | 手で操作すると**手や腕が写り込んで影になります**。足で踏めば手は紙から離れています |
| **自動傾き補正** | 入 | 台紙の見分けに余裕が出ます |
| **自動切り出し（トリミング）** | **紙のまわりに余白を残す**設定に。きつく切りすぎない | 紙の端ぎりぎりで切ると、絵が写真の縁に触れて**絵が丸ごと消える**ことがあります |

> 設定の名前は、お使いのソフトの版によって違うかもしれません。
> **大事なのは「JPGで」「決まったフォルダへ」「通し番号で」保存されること**です。
> その3つさえ満たせば、名前は何でも構いません。

### 2-4. 紙を置く場所を白くする ★ 見落としやすい

**スキャナの下に敷くマットが黒い場合、使わないでください。**
白い紙（模造紙・A3のコピー用紙など）を敷いてください。

> **なぜか（実測）**
>
> 上から撮る方式だと、台紙の**外側の台まで写真に写ります**。
> 台が黒いと、そこが「紙ではない＝クレヨンと同じ」と判定され、
> **額縁のような塊**になります。前回このせいで、
> 台紙の見分けが **11/19 → 6/19** まで落ちました（R-067）。

### 2-5. 通しで1枚試す

スタッフに渡す前に、**実際に色を塗った紙を1枚**スキャンしてください。

**合格**: アプリを触らずに、数秒で絵が泳ぎ出す。

ここで泳がなければ、§6「困ったとき」を見てください。
**朝にまとめて確認するのでは遅い**ので、前日にここまでやります。

## 3. 当日の朝（30分）

1. PC・スキャナ・モニターをつなぐ
2. アプリを起動する
3. `S` キーで設定を開き、**テーマ**（水族館／ダイナソー）を今日のものにする
4. **取り込みフォルダが前日のままか**確認する
5. `S` キーで設定を閉じ、`F` キーで全画面にする
6. **試しに1枚スキャンして、泳ぎ出すのを見る**
7. 泳いだ絵を `S` → 一覧から消しておく（試し用なので）

**ここまでで運営者の仕事は終わりです。** あとはスタッフに任せられます。

---

## 4. 当日の運用（スタッフ用）

> **この節だけを印刷して、スキャナの横に貼ってください。**

### やること

1. 台紙を渡す。**「絵の中を塗ってね」と一言添える**
2. 描けた紙を受け取る
3. **スキャナの下に、まっすぐ置く**
4. **フットペダルを踏む**
5. 紙を返す

**アプリは触りません。** 数秒で画面に泳ぎ出します。

### 紙の置き方

- **まっすぐ置く**（少しの傾きは大丈夫。大きく斜めだとうまくいきません）
- **紙のまわりに余白を空ける**。ぎりぎりまで寄せない
- **手や腕を紙の上に残さない**。影になります
- 紙は**1枚ずつ**。2枚重ねない

### 声かけ

**「絵の中を塗ってね」** が一番効きます。

絵の外の余白いっぱいに落書きすると、うまく見分けられないことがあります。
早く塗り終わった子には、余白を埋めてもらう前に**次の紙を渡す**のも手です。

### 画面に出ないとき

**同じ紙をもう一度スキャンしてください。** それで大体直ります。

2回やっても出ない紙は、**取っておいて運営者に渡してください**。
（捨てないでください。あとで直すための唯一の手がかりになります）

---

## 5. 終わったら — イベントを終える

**その日のうちにやってください。** 次の会期の絵と混ざります。

1. `S` キーで設定を開く
2. 「**イベントを終える**」の欄に、**会場の名前**を入れる（例: `イオン久御山店`）
3. 「**絵を片付けて次へ**」を押す
4. 確認が出るので、内容を読んで「OK」

これで、**その会期の絵と、元のスキャン写真がまとめて**
`events/2026-09-12 イオン久御山店/` のような日付つきフォルダへ移ります。

**消えません。移すだけです。** 画面は空になりますが、
フォルダを開けばそのまま残っています。

**取り込みフォルダとテーマの設定は残る**ので、
次の会期の朝に選び直すことにはなりません。

### 何が残るか

```
events/2026-09-12 イオン久御山店/
  pieces/       泳いでいた絵（切り抜き済み）
  pieces.json   その台帳
  scans/        スキャナが撮った元の写真 ← これが一番大事
```

**`scans/` が一番大事です。** 不具合を調べられるのはこれだけです。
実際、プテラノドンが飛ばなかった原因は、**実物の紙が手元に来て初めて**
分かりました（R-069）。合成データでは一度も再現できませんでした。

### 持ち帰るもの

- 上のフォルダ（**丸ごとバックアップを取る**。PCが壊れたら二度と戻りません）
- **うまくいかなかった紙**（スタッフから受け取ったもの）
- 参加人数・気づいたこと

## 6. 困ったとき

| 症状 | 見るところ |
|---|---|
| **1枚も泳がない** | スキャナの**保存形式が PDF** になっていませんか。**JPG** にしてください |
| **1枚も泳がない** | スキャナの**保存先**が取り込みフォルダになっていますか（`S` キーで確認できます） |
| **ある紙だけ泳がない** | もう一度スキャンする。**それでも駄目なら紙を取っておく** |
| **絵が真っ黒／変な四角が泳ぐ** | 敷いているマットが黒くありませんか。**白い紙を敷いてください** |
| **絵の中が透けている・消えている** | 影です。**トップLEDを点ける**／手を紙の上に残さない |
| **絵が縦に潰れて見える** | 紙をぎりぎりまで寄せて撮っていませんか。**まわりに余白を空けて**ください |
| **絵が途中から取り込まれなくなった** | スキャナのファイル名が `img001` に戻る設定になっていませんか。**通し番号にしてください** |
| **前回の絵が混ざっている** | §5 の「イベントを終える」をやらずに始めています。いまからでもできます |
| **画面がカクつく** | `S` キー →「飾りの多さ」を下げる／「しなりの強さ」を 0 にする |
| **起動時に警告が出る** | `docs/警告が出て起動できないとき.md` |

**どれにも当てはまらないときは、うまくいかなかった紙を取っておいてください。**
紙さえあれば、あとから原因を特定して直せます。
