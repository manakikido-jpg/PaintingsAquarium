# 機能要項（実装機能一覧）

実装・追加した機能を継続的にまとめる台帳。
**機能を追加・変更したら必ず本ファイルを更新すること。**

- 最終更新: 2026-08-24
- 関連: `docs/推奨スペック.md`（実測値）／`docs/会場PCの選び方.md`（買う機種の判断）

凡例: ✅ 実装済 / 🟡 雛形（枠のみ） / ⬜ 未着手

---

## 機能ID の付け方

カテゴリごとに百番台を割り当て、通し番号にする。
**一度振った番号は変えない。** 番号でドキュメント間を参照するため。

| 番号帯 | カテゴリ |
|---|---|
| 100 | 基盤・共通（起動・設定・保存） |
| 200 | 取り込み（監視・透過・トリミング） |
| 300 | 水槽（描画・アニメーション・全画面） |
| 400 | 運営（一覧・削除・集計） |
| 500 | テーマ（世界の差し替え） |
