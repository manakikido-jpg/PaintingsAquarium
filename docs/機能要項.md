**機能を追加・変更したら必ず本ファイルを更新すること。**

凡例: ✅ 実装済 / 🟡 雛形（枠のみ） / ⬜ 未着手

## 機能ID の付け方

カテゴリごとに百番台を割り当て、通し番号にする。
**一度振った番号は変えない。** 番号でドキュメント間を参照するため。

| 番号帯 | カテゴリ |
|---|---|
| 100 | 基盤・共通（起動・設定・保存） |
| 200 | 取り込み（監視・透過・トリミング） |
| 300 | 水槽（描画・アニメーション・全画面） |
| 400 | 運営（一覧・削除・集計） |
| 500 | テーマ（世界の差し替え） |

## 追加機能ログ（新機能を足したら追記）

**強調（`**太字**`）は、その回の目玉を1つだけ。**

- 2026-08-12 初版: ドキュメント3点セットを整備し、方針を「完全オフラインのデスクトップアプリ」に確定。
  機能は F-101〜F-403 を台帳として先に登録（全て未着手）。実装コードはまだ0行。
- 2026-08-12 F-101〜F-403, F-205: **写真をフォルダに置くだけで絵が水槽を泳ぐところまで通した**。
  切り抜きの判定（F-202 / F-203 / F-205）と泳ぐ軌道（F-302）は純粋関数に切り出し、
  単体テスト 51 件で固定。取り込みの通し確認で R-002 と R-003 を踏み、両方とも直して規則に記録。
  残るのは F-404（インストーラ）。
- 2026-08-12 F-404: **Windows インストーラ（NSIS・77MB）をビルドできるようにした**。
  対象OSを Windows のみに縮小（macOS 取りやめ）。管理者権限が無くても入れられる
  ユーザー単位インストールにしてある。**Windows 実機での動作確認は未実施**。
- 2026-08-12 F-306: **水槽の背景を作った**（水面の光・差し込む光の筋・上がる泡・周辺減光）。
  主役は子どもの絵なので、背景はすべて低い不透明度に抑え、会場で弱められるよう
  「背景の強さ」スライダー（0〜1）を追加。0 にすると無地に戻る。
  通し確認で絵が重なって見える問題を見つけ、生成位置を横にも散らして解消（R-005）。
- 2026-08-12 F-307, F-308: 底の飾り（砂地・岩・揺れる海藻）を追加。すべて**絵より奥**に
  **暗いシルエット**で描き、絵と派手さで喧嘩させない。
  あわせて **絵どうしが避け合うようにした（F-308）**。生成位置を散らすだけでは
  泳ぐうちに合流して重なるため（R-005 追記）。50匹での重なりは実測で 92% 減。
- 2026-08-12 F-309, F-310: 貝殻と沈没船を追加。あわせて **取り込んだ絵が
  「薄く小さく」から「濃く等倍」へふわっと現れるようにした（F-310）**。
  起動前からある絵は演出しない（起動のたびに全部が一斉に現れると不具合に見えるため）。
  シルエットが背景に溶けて沈没船が消える問題を踏み、砂を明るい敷物に、
  上に乗る物を暗い影絵に作り替えた（R-006）。
- 2026-08-14 F-501〜F-504: **テーマの土台と恐竜テーマを追加**。
  同じアプリで世界を差し替えられるようにした。恐竜は空中を漂わず、
  奥行き10列の地面を歩く（`walk.ts`）。絵はテーマごとに分かれる。
  途中で R-007（避け合いが逆効果）・R-008（乱数の種）・R-009（縞模様）を踏み、
  すべて直して規則に記録した。残りは宇宙・森・夜空（F-505〜F-507）。
- 2026-08-14 F-311, F-312: **水面の揺らぎ模様（コースティクス）を入れ、水族館の色を深く沈めた**。
  teamLab のお絵かき水族館を意識した見え方。映すのはモニターで黒が沈むため、
  背景を暗くするほど絵が浮き上がる。絵の後ろに淡い光を置いて輪郭が闇に溶けないようにした。
  速度は小さい面に描いて引き伸ばす方式で確保（480×270 で 1 フレーム 1.1ms）。
- 2026-08-14 F-313, F-314: **背景の「安いシルエット感」を取った**。
  遠景を起動時に焼き付けてぼかし、3段の空気遠近と上面の光の縁、
  塗りのグラデーションを入れた。揺らぎ模様の動きは大げさだったので落とした。
  手前にも毎フレームのぼかしを入れたが **13.7fps → 1.8fps** になったため撤回し、
  薄い halo で代用した（R-012）。速度は `?measure` で実測できるようにした。
- 2026-08-14 F-315: **色味を明るく鮮やかな青に振り直した**（参考: teamLab のお絵かき水族館）。
  底の飾りを黒い影絵から6色のサンゴに変え、砂も明るくした。
  「高級感」を暗さと解釈して逆方向へ作り込んでいたのが原因（R-013）。
  明るい背景でも絵が負けないよう、色数の多い飾りは画面の下に集め、
  絵が泳ぐ中央は情報の少ない青のまま残している。
- 2026-08-16 F-316, F-317: **リハーサル前の実測で見つけた3件を修正**。
  一覧が全件を描いていた（R-014）、絵の大きさが画面幅に追従しなかった（R-015）、
  背景の拡大描画が重かった（R-016・**5.7 → 14.9fps**）。
  あわせて「同時に泳ぐ数」を設定画面から変えられるようにした。
  **`docs/リハーサル手順.md` を作成。次は Windows 実機での通し確認。**
- 2026-08-16 F-318, F-319: **背景を賑やかにした**。枝分かれする形の枝サンゴを追加し、
  飾りの数を設定で 0.4〜2.4 倍まで変えられるようにした（既定 2.0）。
  **増えるのは画面の下だけ**で、絵が泳ぐ中央は空けたまま。
  サンゴは絵より奥に描くので、増やしても絵は隠れない。
