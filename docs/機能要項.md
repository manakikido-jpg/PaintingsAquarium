---

## 機能ID の付け方

カテゴリごとに百番台を割り当て、通し番号にする。
**一度振った番号は変えない。** 番号でドキュメント間を参照するため。

| 番号帯 | カテゴリ |
|---|---|
| 100 | 基盤・共通（起動・設定・保存） |
| 200 | 取り込み（監視・透過・トリミング） |
| 300 | 水槽（描画・アニメーション・全画面） |
| 400 | 運営（一覧・削除・集計） |
