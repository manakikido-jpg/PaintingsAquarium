**機能を追加・変更したら必ず本ファイルを更新すること。**

- 最終更新: 2026-08-24

凡例: ✅ 実装済 / 🟡 雛形（枠のみ） / ⬜ 未着手

---

## 機能ID の付け方

カテゴリごとに百番台を割り当て、通し番号にする。
**一度振った番号は変えない。** 番号でドキュメント間を参照するため。

| 番号帯 | カテゴリ |
|---|---|
| 100 | 基盤・共通（起動・設定・保存） |
| 200 | 取り込み（監視・透過・トリミング） |
| 300 | 水槽（描画・アニメーション・全画面） |
| 400 | 運営（一覧・削除・集計） |
| 500 | テーマ（世界の差し替え） |

## 追加機能ログ（新機能を足したら追記）

**強調（`**太字**`）は、その回の目玉を1つだけ。**

- 2026-08-18 F-408 追記: 配るファイル名から**版番号を外した**。
  「最新版」の置き場にビルドのたびに別名のファイルが積み上がり、
  0.1.0 と 0.1.38 が並んで「どれを落とすのか」が分からない状態になったため。
  毎回同じ2つ（`PaintingsAquarium-Setup.exe` / `-portable.exe`）を上書きする。
  古い名前のファイルはビルドのたびに消す。
  代わりに、**いま動いている版を設定画面に出す**ようにした。
- 2026-08-24 F-218, F-219: **台紙を印刷できる大きさにし、照合で紙の傾きも試すようにした**。

  台紙は長辺 376〜500px しかなく、A4に伸ばすと6倍でギザギザだった。
  ただ拡大しても階段が大きくなるだけなので、**線の輪郭を曲線として取り出してから
  描き直す**道具を作った（`tools/finish-templates.py`・11枚すべて長辺2400px）。

  あわせて、**クラゲとまる魚の見分けが際どい**（差 +0.00）件を測り直した。
  「クラゲを縦長にすれば離れる」と書いていたが（`docs/台紙の作り方.md`）、
  **測ったら効かなかった**。重なりは 0.55 → 0.44 に下がるのに、差は +0.00 → +0.01。
  細い触手が伸びたぶん**自分の台紙との重なりも落ちる**ので、差し引きゼロだった。

  効いたのは**照合のやり方**のほう。それまで 90度ずつしか試していなかったので、
  紙が数度傾いただけで細い形が崩れていた。±8° を 4° 刻みで試すようにした（F-218）。

  | | クラゲの自分との重なり（最低） | 2位との差（最小） |
  |---|---|---|
  | 前 | 0.45 | +0.00 |
  | 縦長にしただけ | 0.45 | +0.01 |
  | **傾きも試す** | **0.72** | **+0.25** |

  6種すべてで 48/48・最小の差 +0.20。恐竜も 40/40 になり、
  **10度でプテラノドンがブロントサウルスと入れ替わっていた件も消えた**
  （前は 39/40・差 -0.05）。R-042。
- 2026-08-24 F-338: **タコ・ウミガメが、ゆっくり上下するようにした**。
  それまでの上下はS字の波だけで、振れ幅が画面の高さの 10〜13% しかない。
  つまり**生まれた高さの帯から一生出られない**。実測（5分）で、ウミガメは
  滞在時間の **49% が画面の最下段**（上から5等分）・最上段は **0%** だった。
  画面の下は岩とサンゴが並ぶ帯なので、そこに居続ける絵は見つけられない
  （要件定義 §3 5c）。波とは別に、**150秒で1往復する上下の動き**を足した。
  直したあと（5分）: ウミガメ 17/15/24/20/23%、タコ 21/20/18/23/19%。
  上下の速さは横より遅いまま（R-035）で、S字の波は 8秒窓で 10〜25% に収めてある。
  `src/core/__tests__/speed.test.ts` で**短い窓と長い窓を別々に**固定した。R-041。
- 2026-08-24 F-308 直し: **絵どうしの避け合いが効いていなかった**のを直した。
  避けを速度とは別の値として持たせ、位置にだけ足すようにした（`nudge`）。
  それまでは速度の向きを変える方式で、タコ・ウミガメ・クラゲの動きに
  **毎フレーム上書き**されていた。実測（24匹・60秒）で触れ合う組が
  平均 3.32 → **0.17 組**。ウミガメの最短距離は 21px → 304px。R-040。
- 2026-08-24 F-511: **プテラノドンが空を飛び、羽ばたくようにした**。
  羽ばたきは**絵を切らずに**やっている。翼を矩形で切ると裂けるので（R-037）、
  絵全体を縦に縮めながら横へ広げる（squash & stretch）。
  切りやすい台紙に作り直す案は**やめた**。塗る場所が 8% しか残らず、
  塗り絵として成立しなかった（R-038）。
  あわせて、飛ぶ絵は地平線より上だけを飛び、足元の影を付けないようにした。
- 2026-08-24 F-511: **プテラノドンの翼が開いて、たたむようになった**。
  台紙をV字ポーズ（翼を背中の上へ持ち上げた横向き）に描き直してもらい、
  **肩の線（y=0.64）で上下に分けて、上だけを縦に伸び縮み**させている。
  回すと裂けるので回さない。伸び縮みは切り目の上が動かないので開かない。
  実測で翼の高さは 95〜120px（±11%）動き、頭と胴は動いていない（幅 ±2%）。
  四足恐竜との重なりも 0.55 → 0.43 に下がった。
- 2026-08-24 F-509 / F-510: **恐竜の台紙5種を照合につなぎ、足を動かして歩くようにした**。
  照合は**テーマの中だけ**に閉じた（混ぜるとまる魚がトリケラトプスになりうる）。
  足は前後2組に分けて逆の拍で振る。切り目は台紙の足元を測って**空いている列**に置いた。
  目分量で切って腹の下が裂けた失敗は R-037 に残した。
  実機（1920×1080・xvfb）で塗った台紙5枚を通して確認。**60fps**。
- 2026-08-24 F-509 準備: **恐竜の台紙5種を入れて測った**（印刷用に外枠は外してある）。
