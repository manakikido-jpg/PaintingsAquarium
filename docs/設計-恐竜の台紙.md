## 測ってわかったこと（`tools/check-templates.py`）

### 1. 恐竜どうしは、水族館の6種より**ずっと似ている**

| 危ない組 | 重なり | 合否（0.55 未満が合格） |
|---|---|---|
| ステゴサウルス ↔ トリケラトプス | **0.67** | NG |
| アンキロサウルス ↔ ステゴサウルス | 0.59 | NG |
| アンキロサウルス ↔ トリケラトプス | 0.58 | NG |
| プテラノドン ↔ トリケラトプス | 0.55 | NG |

当然で、**四足恐竜はどれも「胴＋4本足＋首＋尾」**の形をしている。
海の生き物のように、形そのものを離すのは難しい。

見分けの試験（少し傾ける・少し伸ばす）では **40回とも正解が1位**になったが、
ステゴ ↔ トリケラは差が **+0.04** しかない。実際の紙・色・手ぶれで入れ替わりうる。

### 2. 水族館の台紙と**混ぜてはいけない**

11種を1つの集まりとして照合すると、こうなる。

| 組 | 重なり |
|---|---|
| **まる魚 ↔ トリケラトプス** | **0.69** |
| まる魚 ↔ ステゴサウルス | 0.66 |
| サメ ↔ アンキロサウルス | 0.64 |

塗った魚がトリケラトプスとして判定されうる。
→ **照合はテーマの中だけで行う。** 絵には取り込んだときのテーマが記録されている
（`App.tsx` の `theme: current.theme`）ので、その情報を照合まで渡せばよい。

## 提案する作り

### 照合はテーマごとに閉じる

```
identifySpecies(image, theme)   // その テーマ の台紙だけと照合する
```

`processPhoto` にテーマを渡す。`App.tsx` は取り込み時のテーマを持っているので追加は1行。

### 「どの恐竜か」は当てなくてよい

ここが水族館と決定的に違うところ。水族館では種類ごとに**泳ぎ方が違う**ので、
種類を外すと動きが変わってしまった。恐竜は**歩き方が同じ**なので、
ステゴをトリケラと取り違えても**画面上は何も変わらない**。

台紙から本当に要るのは次の3つだけ。

| 要るもの | なぜ |
|---|---|
| **頭がどちら側か** | 外すと尾から歩く（R-030 と同じ壊れ方） |
| **尾の付け根** | 歩くときに尾を振らせるため |
| **飛ぶか歩くか** | プテラノドンだけ別 |

つまり **ステゴ ↔ トリケラの 0.67 は直さなくてよい。**
直すべきは「プテラノドン ↔ 四足」だけで、こちらは 0.55（差 +0.05）。
やや際どいので、**プテラノドンの台紙だけ作り直す**（翼を大きく広げて横長にする）と安全になる。

### プテラノドンの動き

いまの恐竜テーマは全部 `walk`（地面の列を歩く）。
プテラノドンを歩かせると**翼竜が地面を歩く**ことになる。

## 決めること

### D-6 プテラノドンを飛ばすか

| 案 | 内容 | 手間 |
|---|---|---|
| **A（推奨）** | **空を飛ばす。** 地平線より上を、翼を上下させながら横切る | 動きの層に「飛ぶ」を1つ足す。半日ほど |
| B | ほかと同じように歩く | 追加なし。ただし見た目は不自然 |
| C | プテラノドンの台紙を外す | 追加なし。台紙は5種になる |

### D-7 ステゴ ↔ トリケラの近さ（0.67）を直すか

| 案 | 内容 |
|---|---|
| **A（推奨）** | **直さない。** 取り違えても動きは同じで、画面上は変わらない |
| B | どちらかを作り直して形を離す（背びれをもっと高く、襟をもっと大きく など） |

> B を選ぶ場合でも、**判定のしきい値は下げないこと**（`docs/台紙の作り方.md`）。
