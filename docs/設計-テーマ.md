# 設計: テーマ（水族館 / 恐竜 / …）

- 作成: 2026-08-12
- 状態: **合意待ち。実装は止めている**（`CLAUDE.md`「大きい機能は先に設計を見せる」）

## 何をしたいか

同じアプリで、会場に合わせて世界を差し替えたい。
「お絵かき水族館」だけでなく「お絵かき恐竜」なども出せるようにする。

取り込みの仕組み（フォルダ監視・白の透過・トリミング）は**一切変えない**。
変わるのは「取り込んだ絵をどんな世界で、どう動かすか」だけ。

## テーマが差し替えるもの

| 要素 | 水族館（今あるもの） | 恐竜（作るもの） |
|---|---|---|
| 背景の色 | 深い青。上が明るく下が濃い | 霧のかかった谷。空は夕方寄り |
| 光 | 水面から差し込む光の筋 | 木漏れ日、または霧の層 |
| 漂うもの | 泡（下から上へ） | 胞子・埃（ゆっくり漂う） |
| 地面 | 砂地 | 土と草 |
| 置物 | 岩・海藻・貝殻・沈没船 | 岩・シダ・倒木・骨 |
| **絵の動き** | **泳ぐ**（自由に浮遊、上下にゆらぐ） | **← ここが最大の論点。下記 Q1** |

## 最大の論点：恐竜は「泳がない」

水族館の動きは「画面のどこにでもいられる」前提で作ってある（`swim.ts`）。
恐竜を同じ動きにすると、**恐竜が空中を漂う**。ひと目で変だと分かる。

素直に「地面を歩く」にすると、別の問題が出る。
**地面は1本しかないので、50匹が横一列に並んで詰まる。** 避け合い（F-308）は
上下に逃がすことで効いているので、地面に貼り付くと効かなくなる。

解決するには**奥行きのある地面を数本持つ**必要がある。
奥の列ほど小さく・薄く・画面の上のほうに置き、絵をどれかの列に割り振る。
これで50匹入り、遠近も出る。ただし作りは重くなる。

```
   ← 奥（小さい・薄い）
  ─────────────────  列3
    ───────────────  列2
  ───────────────    列1
   ← 手前（大きい・濃い）
```

## 作り方（合意後）

段階を分ける。第1段階はどの答えでも必要なので、無駄にならない。

**第1段階 — 土台**
今の水族館を「テーマの1つ」として切り出す。**見た目は1ピクセルも変えない。**
`Aquarium.tsx` から背景と装飾の呼び出しをテーマ側へ移し、
設定に「テーマ」を追加する（この時点では選択肢は水族館のみ）。

**第2段階 — 恐竜テーマ**
Q1 の答えに沿って動きを作り、背景と置物（シダ・倒木・骨・岩）を作る。
判定と動きの計算は今までどおり純粋関数＋単体テストで固定する。

**第3段階 — 3つ目以降**
Q2 の答え次第。土台ができていれば、1テーマあたりの追加は背景と置物だけになる。

## あなたに決めてほしいこと

### Q1. 恐竜バージョンで、絵はどう動くべきか

| | 案 | どうなるか |
|---|---|---|
| **A（推奨）** | **地面を歩く**（奥行き3〜5列） | 恐竜らしい。遠近が出て絵も見やすい。ただし動きの仕組みを2種類持つことになり、第2段階が重くなる |
| B | 今と同じように漂う | 実装はほぼゼロ。ただし**恐竜が空中を漂う**ので、作りかけに見える |
| C | 歩く恐竜と飛ぶ翼竜を混ぜる | 見た目は一番よい。ただし**絵の中身は判別できない**ので、どちらにするかは機械的に割り振るしかない。「自分の恐竜が飛んでいる」ことになる |

**推奨は A。** 「恐竜バージョン」と言われて期待されるのは歩く姿で、
B はその期待を外します。C の判別は今の作り（AI不使用）ではできません。

### Q2. 恐竜のほかに、どのテーマが欲しいか（複数可）

- 恐竜だけでよい
- **宇宙**（星・惑星・無重力で漂う）← 動きは水族館と同じで済むので**一番安い**
- **森／草原**（蝶や鳥のように舞う）
- **夜空**（提灯・花火のように昇る）

### Q3. テーマを変えたとき、これまでの絵はどうするか

| | 案 | どうなるか |
|---|---|---|
| **A（推奨）** | **テーマごとに絵を分ける** | 絵にテーマを記録し、そのテーマの絵だけ出す。恐竜イベントに魚が混ざらない。切り替え直後は画面が空になる |
| B | 全部出す | 会期をまたいで全部泳ぐ／歩く。テーマを変えると過去の絵が場違いに見える |

**推奨は A。** 会場で「恐竜の日なのに魚が泳いでいる」のは事故です。

### Q4. テーマの切り替えはどこで行うか

**推奨: 設定画面で選ぶ（`S` キー）。** 会場で1回選ぶだけなので、
スタッフのアプリ操作0回は保てます。ここは推奨のまま進めてよければ、質問は不要です。
