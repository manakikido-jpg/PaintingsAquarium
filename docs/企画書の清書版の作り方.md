# 企画書の清書版（PDF・PowerPoint・Web）の作り方

会場へ渡す PDF（A4 8ページ）と PowerPoint（スライド12枚）、
先方に送る Web版（1枚ものの提案ページ）を作り直す手順。

## 原本はどれか

| ファイル | 役割 |
|---|---|
| `docs/企画書.md` | **文章の原本。** まずここを直す。網羅順（もれなく全部書く） |
| `docs/企画書.html` | 体裁を整えた版。**PDF の元**（`企画書.md` と同じ並び） |
| `docs/お絵かき水族館-企画書.pdf` | 会場へ渡すもの（A4・8ページ）。下のコマンドで作る |
| `docs/お絵かき水族館-企画書.pptx` | 会場へ渡すもの（スライド12枚）。`node tools/make-proposal-pptx.js` で作る |
| `docs/提案ページ.html` | **先方に送る1枚もののWeb版。** 物語順（フック→証拠→課題→解決→…→次の一歩）。
`企画書.html`・`企画書.md` とは**文章の並びも文面も別物**（構成の考え方は `docs/提案資料の作り方.md`）|
| 提案ページの公開版 | https://claude.ai/code/artifact/89c551df-6c5c-433d-bd1c-618bc048e25f |
| 旧Web版（参考・更新していない） | https://claude.ai/code/artifact/119fb141-8c35-4523-87f3-eddc68d7a4d8 |

`docs/企画書.html` は PDF の元（`企画書.md` と同じ内容・同じ並び）。
`docs/提案ページ.html` は**別の原稿**（物語順に組み直したもの）で、Artifact に置いてある
提案ページの公開版と**同じ中身**。それぞれ文言を直したら、対応する清書版を作り直す。

## コマンド

```bash
python3 tools/make-proposal-pdf.py      # PDF（A4・8ページ）
node tools/make-proposal-pptx.js        # PowerPoint（スライド12枚）
```

PDF は Chromium（`/opt/pw-browsers/`）と、Google Fonts を取りに行くための通信が要る。
pptx は `pptxgenjs`（`npm install pptxgenjs`）が要る。

pptx には**費用・いまの状態・ご相談したいこと・氏名／連絡先・開催希望日を入れていない**。
会場で回覧される想定なので、こちらの都合や未確定の数字は口頭で伝える。

## つまずいたところ（同じことを2回やった）

- **日本語が全部化けた** — `docs/企画書.html` には `<meta charset="utf-8">` が無い。
  Artifact は head を自動で足すので画面では正常に見えるが、`file://` で開くと
  Latin-1 と解釈されて化ける。スクリプトが印刷用コピーに charset を足している。
- **フォントが出ない** — Chromium はプロキシの証明書を信用しないので Google Fonts の
  取得に失敗し、既定のゴシックに落ちる。スクリプトは curl で先に落として data URI で
  埋め込む。使う文字だけを `text=` で切り出すので 300KB 程度で済む。
- **白いページが3枚できた** — 印刷CSSで `section { break-inside: avoid }` を全ての節に
  かけると、1ページに収まらない節が丸ごと次ページへ送られる。避けるのは表・箱・行など
  小さい単位だけにする（7ページ → 5ページ）。
