## 1枚でいうと

**子どもが塗った魚が、その場で大画面の海を泳ぎ出す体験です。**

塗り終わった紙をスキャナに通すだけで、**約3秒後**にその絵が水槽の中を泳ぎ始めます。
自分の絵を探して、指をさして、親を呼ぶ。そこまでが1セットの体験です。

会場にお願いするのは**場所・机・電源・モニター**だけです。
**インターネットは使いません**（Wi-Fi をお借りする必要がありません）。
**音も出しません**。個人情報も一切いただきません。

## 来場者の体験（1人あたり 5〜10分）

| | やること | 時間 |
|---|---|---|
| 1 | 6種類の台紙（魚・タコ・イルカ・サメ・クラゲ・ウミガメ）から1枚選ぶ | 30秒 |
| 2 | 好きな色で塗る | 3〜7分 |
| 3 | スタッフに渡す。スタッフがスキャナに通す | 20秒 |
| 4 | **大画面で自分の絵が泳ぎ出す**のを見る | 1〜3分 |
| 5 | **塗った紙はそのまま持ち帰る** | — |

**塗るだけなので、絵が苦手な子でも参加できます。** 台紙の形は決まっているので、
どの子の絵も「ちゃんと魚に見える」まま泳ぎます。

生き物ごとに泳ぎ方が違います。魚は尾びれを振って進み、イルカは時々跳ね、
サメは魚を追いかけ、クラゲはふわふわ漂い、ウミガメはS字を描いて泳ぎます。
**自分が塗ったのがどれかすぐ分かる**ようにするための作り込みです。

## この企画のねらい

- **待たせない。** 塗り終えてから泳ぎ出すまで約3秒です。「描いて終わり」にしない
- **見つけられる。** 同時に泳ぐのは最新の50匹まで。増えすぎて自分の絵を見失わないようにしています
- **持ち帰れる。** 紙は本人のものです。画面の中と手元の両方に残ります
- **繰り返せる。** 1人が2枚描いても仕組みは変わりません
