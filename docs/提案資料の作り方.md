# 提案資料の作り方（調べてまとめたコツ）

- 作成: 2026-09-09
- 目的: 会場向け提案資料（企画書）の「中身」と「見せ方」の質を上げる
- 関連: `docs/企画書.md`（原稿）/ `docs/企画書の清書版の作り方.md`（PDF・PPTX化）

## 調べて分かったこと

海外の提案資料（ピッチデック）と、日本語の提案書、両方を調べた。要点は重なる。

### 1. 結論から書く（見出しが「主張」になっているか）

McKinsey などのコンサル資料では、見出しを「話題」ではなく「その1枚の結論」にする。

| 話題（弱い） | 主張（強い） |
|---|---|
| 実施実績 | すでに2会場・630人に受け入れられている |
| ご心配への回答 | 会場の負担はゼロ、リスクも運用実績で消えている |

見出しだけ読めば話が繋がるようにする（Pyramid Principle／Action Title）。

### 2. 枚数を絞る・1枚1メッセージ

- 短い資料（10〜20枚程度）のほうが読了率・記憶に残る率が高いという調査がある。
- 1枚に詰め込まず、**1枚＝1つの主張**にする。

### 3. 文字より絵。実物・実例で語る

- 図解・実例・写真を多くした資料は、文字だけの資料より反応がよいという調査がある。
- 抽象的な説明より、**具体的な1件の事例**（実際の子・実際の絵）のほうが伝わる。

### 4. 物語の型：課題 → 解決 → 証拠 → 依頼

- 「なぜ要るか（課題）」→「何を提供するか（解決）」→「本当に効くか（証拠・実績）」→
  「次に何をしてほしいか（依頼）」の順で並べると、論理も感情も繋がる。
- 今回は**証拠（実績630人）が本物にある**ので、証拠を早く・強く見せたほうが強い。

### 5. トンマナを揃える（デザインは目立たせるためではない）

- 提案書の価値は中身。デザインを派手にするより、**フォント・色・余白のルールを1つに統一**して
  読みやすくすることが効く（フォント統一・強弱のルール・整列）。
- 使ってよい飾りは、情報の理解を助けるものだけ（強調・区切り・アイコン程度）。

### 6. 相手に合わせる（この提案書の相手は誰か）

- 汎用の資料より、**相手の関心事に合わせた資料**のほうが通りやすいという調査がある。
- 今回の相手はショッピングモールの担当者。関心はおそらく
  「集客になるか」「運営の手間・リスクはないか」「費用は」。この3点に早く答える構成にする。

### 7. 締めは次の行動をはっきり書く

- 「ご相談したいこと」で終わるより、**「この場で決めてほしいこと／次の1歩」**まで書くと動きやすい。

## 今回の提案書に当てはめた構成

1. **フック**（実際の「あっ、わたしの！」の瞬間を1枚で見せる）
2. **証拠を先に**（2会場・630人・ファミリー中心。実物ギャラリー）
3. **課題**（塗り絵だけのイベントは「その場で完結」せず、話題にも記録にも残りにくい）
4. **解決**（3秒で動き出す仕組み・2つの世界）
5. **裏づけ**（なぜこの形にしているか＝設計判断の理由）
6. **会場の関心3点に答える**（集客・運営負担・費用）
7. **次の1歩**（何を決めてほしいか、をはっきり書く）

`docs/企画書.html` は印刷用（会場に渡すPDF・PPTXの元）としてそのまま残す。
今回はこの構成で**Web版（1枚のランディングページ形式）を新しく作り直す**。
