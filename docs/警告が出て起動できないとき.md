# 「WindowsによってPCが保護されました」の通し方

未署名のアプリなので、**この警告は必ず出る**（`docs/要件定義.md` §8 の決定）。
ただし**出さずに済ませる方法がある。** 会場では方法1を使う。

> **この文書の内容は、実機の Windows では確かめていない。**
> 仕組み（下の「なぜ出るか」）から書いたもの。
> リハーサルのときに実際に試して、違っていたらここを直すこと。
>
> **2026-09-03: 発行元の名前を入れた。** それまで exe の「会社名」が
> **空**だった（`package.json` に `author` が無く、electron-builder が
> 毎回警告を出していた）。名前の無いインストーラは
> 「望ましくないアプリ」の判定に引っかかりやすい。
> いまは `manakikido` が入っている（実際に exe を読んで確認した）。
> **これで必ず消えるわけではない。** 判定の中身は公開されていないので、
> 効いたかどうかは実機で見るしかない。

---

## まず: 落とせない（ダウンロードの段階で止まる）

**起動より前で止まっているなら、下の「なぜ出るか」より先にここを読む。**

ブラウザ（Edge / Chrome）は、**未署名の `.exe` を落とす段階で止める。**
「保持する」はダウンロード一覧の「…」の**奥**にあり、
組織のポリシーが入っていると**その選択肢ごと消えている**。
そうなると exe はどうやっても手に入らない。

### まず「どの言葉が出たか」で分かれる

| 画面の言葉 | 何が止めているか |
|---|---|
| 「WindowsによってPCが保護されました」 | **起動**のとき。署名が無いため（下の「なぜ出るか」） |
| 「安全でない可能性があるアプリをブロックしました」 | **ダウンロード**のとき。「望ましくないアプリ」の判定 |
| 「一般的にダウンロードされていません」 | 同上（落とした人が少ないだけ） |

2つめは**別の仕組み**。署名の有無ではなく、
**「インストーラらしい形をしていて、まだ誰も使っていない」**という理由で止まる。
未署名の NSIS インストーラはこの判定に引っかかりやすい。

**`.zip` はこの判定に引っかかりにくい。** インストーラでも自己展開でもない、
ただの書庫だから。まず方法A を試すこと。

それでも止まるときは、判定そのものを一時的に切る。**元に戻せる**
（Windows 11 の「スマートアプリコントロール」と違って、切ったあと戻せる）。

| どこで出たか | 切る場所 |
|---|---|
| Edge のダウンロード | Edge の設定 →プライバシー、検索、サービス →セキュリティ →**「望ましくない可能性のあるアプリをブロックする」をオフ** |
| Windows の通知 | Windows セキュリティ →アプリとブラウザー コントロール →**評判ベースの保護の設定** →**「望ましくないアプリのブロック」をオフ** |

**落とし終えたら戻すこと。** 会場PCが借り物なら、勝手に触らず管理者に相談する。

### 方法A `.zip` を落とす（これが一番早い）

最新版の置き場に **`PaintingsAquarium.zip`** を一緒に置いてある。

    https://github.com/manakikido-jpg/PaintingsAquarium/releases/tag/latest

**中身は exe と同じ**で、ブラウザは zip をここまで強くは止めない。

1. `PaintingsAquarium.zip` を落とす
2. **右クリック →「すべて展開」**
   （「ここに展開」だと **75個のファイルがばらける**）
3. 展開したフォルダの中の **`PaintingsAquarium.exe`** をダブルクリック

インストールは要らない。**絵は exe の隣に貯まる**ので、
フォルダごとUSBに入れて持ち歩ける（持ち運び版と同じ扱い）。

> **展開する前に、zip のほうで方法2（下の「許可する」）をやっておくと楽。**
> zip に付いた印を先に外せば、中から出てくるファイルにも印が付かない。

### 方法B ブラウザを通さずに落とす

PowerShell を開いて、これを貼るだけ。

```
cd ~\Downloads
curl.exe -L -o PaintingsAquarium.zip https://github.com/manakikido-jpg/PaintingsAquarium/releases/download/latest/PaintingsAquarium.zip
```

**ブラウザを通さないので止められず、「よそから来た印」も付かない。**
`.zip` を `.exe` に変えれば exe も落とせる。

### 方法C 別のPCで落として、USBで運ぶ

自宅PCなど、止められない環境で落として USB にコピーする。
**USB へコピーした時点で印も落ちる**ので、起動時の警告も出なくなる。
会場PCが借り物で、こちらから何も変えられないときはこれが確実。

## ここから下は「落とせたが、起動できない」とき

## なぜ出るか

出るには**2つ揃う**必要がある。

1. アプリに**署名が無い**（証明書を買っていない）
2. ファイルに**「よそから来た印」が付いている**

2つめの印は、ブラウザでダウンロードしたときに Windows が付ける目印
（Mark of the Web）。**これが無ければ、署名が無くても警告は出ない。**

以下はどれも「2つめを外す」やり方。

---

## 方法1 USBメモリで持ち込む（会場向け・一番確実）

1. ダウンロードした exe を、**USBメモリにコピーする**
2. 会場PCに挿して、**USBの中の exe を直接ダブルクリック**

これで警告は出ない。

「よそから来た印」は **NTFS という形式のディスクにしか付けられない。**
市販のUSBメモリはたいてい exFAT か FAT32 で、**コピーした時点で印が落ちる。**

> **USBを自分で NTFS で初期化していると、印は残る。**
> その場合は方法2を先にやってからコピーする。
> 形式は、USBを右クリック →プロパティ →「ファイルシステム」で分かる。

持ち運び版（`PaintingsAquarium-portable.exe`）はもともとUSB運用なので、
**この方法と相性がよい**。絵も exe の隣に貯まるので、USBごと持ち帰れる。

---

## 方法2 チェックを1つ入れる

ダウンロードしたPCで直接起動したいとき。

1. exe を**右クリック** →**プロパティ**
2. 「全般」タブの**一番下**に、こう書かれた行がある

   > セキュリティ: このファイルは他のコンピューターから取得したものです。
   > このコンピューターを保護するため、このファイルへのアクセスはブロックされる可能性があります。

3. その右の**「許可する」にチェック** →**OK**

以後、ダブルクリックしても警告は出ない。

PowerShell でもよい。

```
Unblock-File .\PaintingsAquarium-Setup.exe
```

> **この行が見当たらないときは、もう印が付いていない。**
> それでも警告が出るなら、下の「効かないとき」を見る。

---

## 方法3 その場でしのぐ

**会場でこれをやらないこと。** 事前に方法1か2を済ませておく。

青い窓には、大きく**「実行しない」だけ**が見える。
**左下に小さく灰色で「詳細情報」**がある。**そこを押すと「実行」が出る。**

**ここで詰まる人がほとんど。** 「実行」ボタンが最初から見えないため、
「押せるボタンが1つしか無い＝詰んだ」と見える。

---

## 効かないとき: スマートアプリコントロール

Windows 11 の**スマートアプリコントロール**が「オン」だと、
**上のどれも効かない。** 署名の無いアプリを一切動かさない仕組みのため。

確認する場所:

    Windows セキュリティ →アプリとブラウザー コントロール
    →スマートアプリコントロールの設定

> **オフにすると、二度とオンに戻せない**（Windows を入れ直すまで）。
> 会場PCが借り物なら、**勝手に触らず管理者に相談すること。**
> 新しく買ったPCで有効なことがあるので、
> 受け入れ確認（`docs/会場PCの選び方.md` §10）のときに一緒に見ておく。

## 署名証明書を買えば消えるか

**すぐには消えない。** ここは誤解しやすい。

| | |
|---|---|
| 普通の証明書（OV） | 買っても**しばらく警告は出続ける**。SmartScreen は「どれだけ使われたか」の実績で判断するので、実績が貯まるまで変わらない |
| EV 証明書 | 買った時点で消える。ただし高く、ハードウェアの鍵が要る |

つまり**「買えば解決」ではない。** 会場PC1台に対して見合わないという判断
（`docs/要件定義.md` §8）は、いまも変えていない。

> 近年は Azure Trusted Signing のような**月額の仕組み**も出てきている。
> ただし本人確認（組織の実在年数など）の条件があるので、
> 使えるかどうかは調べないと分からない。**いま急いで買う必要はない。**

## 会場でやること（まとめ）

リハーサルの日に**1回だけ**やる。当日は何もしない。

1. **落とすのは会場PCでやらない。** 手元のPCで落として、USBメモリに入れて持ち込む
   （落とせないときは上の方法A〜C）
2. 会場PCに挿して、USBの中から起動する。**警告は出ないはず**
3. 出たら方法2（「許可する」にチェック）。
   それでも出たらスマートアプリコントロールを見る
4. 通ったら、**そのまま設定まで済ませる**（`docs/リハーサル手順.md`）

**当日にダウンロードしようとしない。** 落とせなかった時点で展示が始まらない。
