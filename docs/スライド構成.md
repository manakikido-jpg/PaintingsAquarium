# スライド構成（自分でスライドを作るときの下敷き）

- 作成: 2026-09-09
- 目的: Canva等でスライドを自作するときの構成メモ。1枚＝1スライドの単位でまとめてある
- 元にした考え方: `docs/提案資料の作り方.md`（結論から書く見出し・1枚1メッセージ・
  文字より実例・課題→解決→証拠→依頼の型）
- 使う素材: `canva素材.zip`（画像14点）で渡し済み。文章は下にコピペできる形で置く

---

## 作成するときのポイント（5つだけ）

1. **見出しは「話題」ではなく「結論」にする。**
   例: 「実施実績」ではなく「すでに2会場・630人に受け入れられている。」
   見出しだけ読んでも話が繋がるようにする。下の各スライドの見出しは、
   この形（結論の一文）で書いてある。そのまま使ってよい。

2. **1枚1メッセージ。詰め込んだら分ける。**
   下は14枚に割ってある。これ以上まとめて枚数を減らそうとしない
   （減らすと1枚に2つの話が入って伝わりにくくなる）。

3. **文字を減らし、絵を大きく。**
   本文はどのスライドも3〜4行以内に収まる分量にしてある。
   写真は`canva素材.zip`のものを画面の半分以上を使って大きく置く。

4. **色は「水族館＝青系」「恐竜＝土色系」で塗り分ける。**
   これが今回の提案書の軸。他のスライドは白・生成り（ベージュ）を基本にして、
   この2枚だけ背景色を変えると、2つの世界があることが一目で伝わる。

5. **最後は「次に決めてほしいこと」で締める。**
   「ご質問・ご相談」で終わらせず、具体的に5点、番号付きで書く（下に用意した）。

---

## 全体の流れ（14枚）

フック → 証拠 → 課題 → 解決 → 設計理由 → 2つの世界（2枚）→
会場の心配ごと → 費用 → 次の一歩、の順。証拠（実績）を課題より前に置くのがポイント
（先に「もう動いている」と示してから課題の話をしたほうが説得力が出る）。

---

### 1. 表紙

**見出し**: 紙が、3秒で水槽を泳ぎだす。

- サブ: 子どもが塗った絵を大画面に泳がせ・歩かせる体験です。
- バッジ的に一言: すでに2会場・のべ630人のお子さまに参加いただいています。
- 画像: `変換前後.jpg`（写真→画面の変化が一目で伝わるので表紙向き）
- 下部に小さく: 出張ワークショップのご提案

### 2. 実施実績（数字）

**見出し**: すでに2会場・630人に受け入れられている。

大きな数字4つを並べる（フォントを一番大きくする箇所）:

| 数字 | 説明 |
|---|---|
| 630人 | のべ参加人数 |
| 2会場 | 実施会場数 |
| 4日間 | 実施日数 |
| 約3秒 | 動き出すまでの時間 |

内訳の表:

| 会場 | 実施期間 | 参加人数 |
|---|---|---|
| イオン久御山店 | 2日間 | 420人 |
| イオン大日店 | 2日間 | 210人 |
| 合計 | 4日間 | 630人 |

補足（小さめの文字で3行）:
- 来場層はファミリーが中心
- 体験の終わりにアンケートへ案内する導線もスムーズだった
- 運用中の不具合は実物データで検証し、その都度直している

### 3. 実施実績（写真）

**見出し**: 実際に会場で塗られた絵です。

- 画像: `いろいろな絵.jpg`（大きく全面に）
- キャプション: 水族館5種・恐竜5種、すべて実物。同じ台紙でも同じ絵は1枚もない。

### 4. 課題

**見出し**: 「描いて終わり」は、話題にならない。

比較を2枚のカードで並べる（このスライドの本体）:

| よくある塗り絵コーナー | お絵かき水族館・ダイナソー |
|---|---|
| 塗って渡して終わり。会場での体験はそこで完結する | 塗った絵がその場で大画面を泳ぎ・歩き出す。「あっ、わたしの！」の瞬間が生まれる |

### 5. 解決

**見出し**: 仕組みはシンプル。約3秒とタップ0回。

- 画像: `変換前後.jpg`（表紙と同じ画像を再掲してよい。ここでは本文とセットで説明する）
- 本文: 紙の色も、はみ出た線も直さない。撮った通りの絵が、そのまま動き出す。
  会場のスタッフが触るのはスキャナだけ。

### 6. 流れ（5ステップ）

**見出し**: 1人あたり5〜10分。

番号付きで5つ（1枚に収める。分けない）:

1. テーマ・台紙を選ぶ（水族館6種／恐竜5種）— 30秒
2. 好きな色で塗る — 3〜7分
3. スタッフに渡す → スキャン — 20秒
4. 画面に自分の絵が現れる — 1〜3分（**ここが山場。強調する**）
5. 塗った紙を持ち帰る

### 7. なぜこの形にしているか

**見出し**: この形にしているのは、全部理由があります。

カード4枚（2×2）:

| なぜ塗り絵か | なぜ3秒か |
|---|---|
| 白紙だと描ける子・描けない子が分かれる。台紙なら全員が同じスタートラインに立てる | 「あとで映ります」では因果が切れる。その場で動くから驚きと達成感になる |

| なぜ絵を直さないか | なぜ50匹までか |
|---|---|
| はみ出しも塗り残しもそのまま動く。直すと「自分の絵」でなくなる | 増えすぎると自分の絵を見失う。古い絵は画面の外へ去るだけ |

### 8. 世界1：お絵かき水族館

**見出し**: お絵かき水族館（背景を海色に）

- 画像: `画面-水族館-実物.jpg`
- 種類（色つきの丸＋名前で6つ並べる）: 魚・イルカ・サメ・タコ・クラゲ・ウミガメ
- 一言: 動きで見分けられるので、自分が塗ったのがどれか、すぐ分かる

### 9. 世界2：お絵かきダイナソー

**見出し**: お絵かきダイナソー（背景を土色に）

- 画像: `画面-恐竜-実物.jpg`
- 種類: アンキロサウルス・ブロントサウルス・ステゴサウルス・トリケラトプス・プテラノドン
- 一言: 平原を歩く4種と、空を飛ぶ1種。水族館と同じ日に両方実施できる

### 10. 会場の心配ごと

**見出し**: 気になる3点に、先にお答えします。

3枚並列のカード（Q→結論→補足の順）:

| 集客になりますか | 運営の負担はありますか | 費用の負担はありますか |
|---|---|---|
| **実績があります。** イオン久御山店は2日間で420人 | **場所だけお借りします。** 機材・机・画材まで持ち込み | **ありません。** お借りするのは場所だけ |

（そのほかの質問はスライドに入れず、口頭 or 別紙で対応してよい。詰め込みすぎない）

### 11. 費用

**見出し**: 費用の内訳。

| 項目 | 金額 | 備考 |
|---|---|---|
| 台紙の印刷 | 〈◯〉円 | 〈200〉枚 |
| クレヨン・色鉛筆 | 〈◯〉円 | 使い回せる |
| 什器（机・椅子） | 〈◯〉円 | レンタルの場合。手持ちなら0円 |
| 機材 | 0円 | 手持ちのPC・スキャナ・モニター |
| ソフト | 0円 | 自作。月額費用も無し |

### 12. 次の一歩

**見出し**: 次に決めていただきたいこと。

番号付きで5つ（依頼を具体的に）:

1. 設置場所（人の流れの中か、落ち着ける場所か）
2. 電源（コンセント1口。難しければポータブル電源を持参）
3. 想定来場者数（実績は1日あたり105〜210人）
4. 搬入・搬出の経路と時間
5. テーマ（水族館・恐竜のどちらか、または両方）

末尾に小さく: 開催希望日〈　〉／実施時間〈　〉／ご提案〈氏名・連絡先〉

## 色（水族館＝青／恐竜＝土色で塗り分ける）

| 用途 | 色 |
|---|---|
| 水族館の背景・見出し | 青系（#0B6FA4 前後） |
| 恐竜の背景・見出し | 土色系（#C9782B 前後） |
| それ以外の背景 | 白 or 生成り |
| 強調（数字・ボタン） | 上記どちらかの濃い色、または差し色のオレンジ |

フォントは日本語なら丸みのあるゴシック体（見出し）＋読みやすいゴシック体（本文）の
組み合わせが今回のトーンに合う（Canvaなら「たぬき油性マジック」「Zen丸ゴシック」＋
「Noto Sans JP」など）。
