# 配布手順（Windows）

- 最終更新: 2026-08-12
- 対象: Windows のみ（macOS は取りやめ。要件定義 §4）

## インストーラを作る

```sh
npm run dist:win
```

`release/PaintingsAquarium Setup 0.1.0.exe`（約 77MB）ができる。

### Windows 以外のマシンで作る場合

Linux から作るには wine が要る。64bit の wine だけでは
`wine: failed to load ntdll.dll` で失敗するので、32bit も入れること。

```sh
apt-get install -y --no-install-recommends wine
dpkg --add-architecture i386
apt-get update
apt-get install -y --no-install-recommends wine32:i386 libgd3:i386
```

`libgd3:i386` を明示しないと `wine32:i386` の依存解決が壊れる。

Windows 上でビルドするならこの準備は要らない。

## 会場PCに入れる

1. `PaintingsAquarium Setup 0.1.0.exe` を会場PCにコピーして実行する
2. **「WindowsによってPCが保護されました」が出る。**
   これは想定どおり。署名証明書を買っていないため必ず出る。
   **「詳細情報」→「実行」** で進む
3. インストール先を選ぶ（既定のままでよい）。
   **管理者権限は要らない**（ユーザー単位インストールにしてある）
4. 起動して、写真を入れるフォルダを選ぶ。**設定はこの1回だけ**

## 会場での運用

| やること | 頻度 |
|---|---|
| 撮った写真を取り込みフォルダに入れる | 随時（アプリの操作は不要） |
| `S` キーで一覧を開き、不適切な絵を消す | 気づいたとき |
| `F` キーで全画面にして大画面に映す | 起動時に1回 |

**取り込みフォルダを会期中に消さないこと。**
アプリ側のデータを失っても、写真さえ残っていれば全部やり直せる。
これが唯一のバックアップ（要件定義 §5）。
