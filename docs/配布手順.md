# 配布手順（Windows）

- 最終更新: 2026-08-17
- 対象: Windows のみ（macOS は取りやめ。要件定義 §4）

## 3つの配り方

| 方法 | 何が要るか | 向いている場面 |
|---|---|---|
| **A. GitHub で作って落とす**（推奨） | ブラウザだけ | 会場PC・予備機に何も入れたくない |
| B. Windows PCで自分で作る | Node.js 20以上 | 手元で試す・改造する |
| C. Linux/macOS で作る | wine（面倒） | 開発機が Windows でないとき |

**どれで作っても、できる exe は同じ2種類。**

| ファイル | 何か |
|---|---|
| `PaintingsAquarium Setup 0.1.0.exe` | **インストール版**。PCに入れて使う |
| `PaintingsAquarium-0.1.0-portable.exe` | **持ち運び版**。入れずにそのまま動く |

---

## A. GitHub で作って落とす（推奨）

`.github/workflows/build-windows.yml` が、push のたびに GitHub の Windows マシンで
テスト → ビルドまでやる。**別PCに Node.js を入れなくてよい**のがこの方法の価値。

1. GitHub のリポジトリを開く
2. 上の **Actions** タブ → 左の **Windows ビルド**
3. 最新の緑チェックの実行を開く
4. 下の **Artifacts** の `PaintingsAquarium-windows` を押すと zip で落ちる
5. zip を展開すると、上の2つの exe が入っている

手で走らせたいときは、同じ画面の **Run workflow** から。

> **テストが落ちたらビルドしない**ようにしてある。
> 緑チェックが付いていない実行の成果物は使わないこと。

---

## B. Windows PC で自分で作る

```
git clone https://github.com/manakikido-jpg/PaintingsAquarium.git
cd PaintingsAquarium
git checkout claude/product-dev-guidelines-85ic9x
npm install
npm run dist:win
```

`release\` に上の2つの exe ができる。Windows なら準備は Node.js だけでよい。

## C. Linux / macOS で作る

wine が要る。64bit の wine だけでは `wine: failed to load ntdll.dll` で失敗するので、
32bit も入れること。

```sh
apt-get install -y --no-install-recommends wine
dpkg --add-architecture i386
apt-get update
apt-get install -y --no-install-recommends wine32:i386 libgd3:i386
```

`libgd3:i386` を明示しないと `wine32:i386` の依存解決が壊れる。

> **wine で作った exe が Windows で起動するところは、まだ一度も確認していない。**
> 会場に持ち込む版は A か B で作ること。

## 別PCで使う

### インストール版

1. `PaintingsAquarium Setup 0.1.0.exe` をコピーして実行する
2. **「WindowsによってPCが保護されました」が出る。**
   これは想定どおり。署名証明書を買っていないため必ず出る。
   **「詳細情報」→「実行」** で進む
3. インストール先を選ぶ（既定のままでよい）。
   **管理者権限は要らない**（ユーザー単位インストールにしてある）
4. 起動して、写真を入れるフォルダを選ぶ。**設定はこの1回だけ**

### 持ち運び版（USB運用）

1. `PaintingsAquarium-0.1.0-portable.exe` を USB にコピーする
2. 会場PCで直接ダブルクリックする（インストールされない）
3. 同じ SmartScreen の警告が出る。同じく「詳細情報」→「実行」

**絵と設定は exe の隣の `PaintingsAquarium-Data` フォルダに入る。**
だから USB ごと別のPCへ挿せば、絵もそのまま付いてくる。

| | 保存先 |
|---|---|
| インストール版 | `C:\Users\<名前>\AppData\Roaming\PaintingsAquarium\data` |
| 持ち運び版 | exe の隣の `PaintingsAquarium-Data\data` |

保存先はアプリの `S` キーの設定画面にも出る。**迷ったらそこを見る。**

> **2つの版は絵を共有しない。** 同じPCで両方使うと「絵が消えた」ように見える。
> どちらか一方に決めて使うこと。

### 絵ごと引っ越す

上の表のフォルダを丸ごとコピーして、移した先の同じ場所に置けばよい。

ただし **取り込みフォルダの写真さえ残っていれば、入れ直すだけで全部やり直せる**。
これが唯一のバックアップ（要件定義 §5）ので、写真のほうを確実に残すこと。

## 会場での運用

| やること | 頻度 |
|---|---|
| 撮った写真を取り込みフォルダに入れる | 随時（アプリの操作は不要） |
| `S` キーで一覧を開き、不適切な絵を消す | 気づいたとき |
| `F` キーで全画面にして大画面に映す | 起動時に1回 |

**取り込みフォルダを会期中に消さないこと。**

## 未確認のこと

- **Windows 実機でのインストールと起動は確認していない。**
  開発環境が Linux のため、ビルドが通ったことまでしか確かめられていない。
  会場に入れる前に、必ず1台で通しの確認をすること（`docs/リハーサル手順.md`）。
- **持ち運び版を実際に USB から動かしたことはない。**
  保存先を切り替える判定は単体テストで固定してあるが、
  「USBから起動して絵が USB に入る」ところは実機でしか確かめられない。
- しきい値の既定値は実物の写真で合わせていない（D-1）。
  会期前に何枚か試し、設定画面のスライダーで調整すること。
