# 配布手順（Windows）

- 最終更新: 2026-08-17
- 対象: Windows のみ（macOS は取りやめ。要件定義 §4）

## 3つの配り方

| 方法 | 何が要るか | 向いている場面 |
|---|---|---|
| **A. 「最新版」から落とす**（推奨） | ブラウザだけ・**ログイン不要** | 会場PC・予備機に何も入れたくない |
| B. Windows PCで自分で作る | Node.js 20以上 | 手元で試す・改造する |
| C. Linux/macOS で作る | wine（面倒） | 開発機が Windows でないとき |

**どれで作っても、できる exe は同じ2種類。**

| ファイル | 何か |
|---|---|
| `PaintingsAquarium-Setup.exe` | **インストール版**。PCに入れて使う |
| `PaintingsAquarium-portable.exe` | **持ち運び版**。入れずにそのまま動く |

---

## A. 「最新版」から落とす（推奨）

**常にここに最新の exe が置いてある。** ログインは要らない。

https://github.com/manakikido-jpg/PaintingsAquarium/releases/tag/latest

`.github/workflows/build-windows.yml` が、push のたびに GitHub の Windows マシンで
テスト → ビルド → ここへ上書き、までやる。**別PCに Node.js を入れなくてよい**。

> **ファイル名は毎回同じ。** 版番号を名前に入れると、置き場にビルドのたびに
> 別名のファイルが積み上がり、会場で「どれを落とすのか」が分からなくなる
>（実際に 0.1.0 と 0.1.38 が並んだ）。
> **いま動いている版は設定画面（`S` キー）の「アプリの版」に出る。**

### 更新するとき

1. 上のページから新しい exe を落とす
2. インストール版なら**そのまま実行**（上書きインストール）。持ち運び版なら**古い exe と差し替える**

> **絵と設定は消えない。** 保存先はアプリと別だから（インストール版は
> `%APPDATA%\PaintingsAquarium\data`、持ち運び版は exe の隣の `data`）。
> 心配なら、更新の前にそのフォルダをコピーしておけば確実。

### 古い方法（Artifacts）

Actions タブ → **Windows ビルド** → 緑チェックの実行 → **Artifacts**。
**GitHub にログインが必要で、60日で消える。** 上の「最新版」で足りるので、
特定の回のビルドが要るときだけ使う。

> **テストが落ちたらビルドしない**ようにしてある。
> 緑チェックが付いていない実行の成果物は使わないこと。

### アプリの中から更新する（インストール版だけ）

設定画面（`S` キー）に **「更新を確認」** がある。

- **押したときだけ**外へ見に行く。起動時には見に行かない
- 新しい版があれば「新しい版 x.y.z を入れる」が出る。押すと落として、
  **アプリを閉じたときに入れ替わる**（会期中に画面が切り替わったりはしない）
- ネットにつながっていなければ「つながりませんでした」と出るだけ。**壊れない**
- **持ち運び版は対象外**（仕組み上その場で入れ替えられない）。
  上の「最新版」ページから落として差し替える

> 会期中は誰も押さないので、**これまでどおり通信ゼロで動く**。
> 準備のときだけネットにつないで押す運用を想定している（2026-08-18 決定）。

版番号は**ビルドのたびに 0.1.<ビルド番号> へ上がる**。
毎回 0.1.0 のままだと「新しい版かどうか」を判断できないため。

## B. Windows PC で自分で作る

```
git clone https://github.com/manakikido-jpg/PaintingsAquarium.git
cd PaintingsAquarium
git checkout claude/product-dev-guidelines-85ic9x
npm install
npm run dist:win
```

`release\` に上の2つの exe ができる。Windows なら準備は Node.js だけでよい。

## C. Linux / macOS で作る

wine が要る。64bit の wine だけでは `wine: failed to load ntdll.dll` で失敗するので、
32bit も入れること。

```sh
apt-get install -y --no-install-recommends wine
dpkg --add-architecture i386
apt-get update
apt-get install -y --no-install-recommends wine32:i386 libgd3:i386
```

`libgd3:i386` を明示しないと `wine32:i386` の依存解決が壊れる。

> **wine で作った exe が Windows で起動するところは、まだ一度も確認していない。**
> 会場に持ち込む版は A か B で作ること。

## 更新できないとき（0.1.73 以前）

**0.1.73 以前は、アプリの「更新」ボタンでは新しい版になりません。**
落とすところまでしかできず、入れ替えは終了時に静かにやる作りだった。
未署名のこのアプリでは Windows がそれを止めるので、**何も起きずに終わる**（R-047）。

直したのは **0.1.74 から**。つまり **0.1.73 以前は、その直し自体を
更新の仕組みで受け取れない**（R-049）。**1回だけ手で入れ替える。**

1. `PaintingsAquarium-Setup.exe` を落とす（落とせなければ `PaintingsAquarium.zip`）
2. **そのまま実行する。** いまのを消す必要は無い。上書きされる
3. `S` キーで版番号が上がっていることを確かめる

**絵と設定は消えない。** 保存先はアプリの外（`%APPDATA%`）なので、
上書きしても中身はそのまま。

一度 0.1.74 以降にすれば、次からは設定画面の
**「いま入れ替えて再起動する」**で更新できる。

## 別PCで使う

> **落とす段階で止められることがある。**
> ブラウザは未署名の `.exe` をダウンロードの時点でブロックする。
> そのときは同じ置き場の **`PaintingsAquarium.zip`**（中身は同じ）を落とす。
> 詳しくは `docs/警告が出て起動できないとき.md`。

### zip 版（落とせないときはこれ）

1. `PaintingsAquarium.zip` を落とす
2. **右クリック →「すべて展開」**（「ここに展開」だとファイルがばらける）
3. 中の `PaintingsAquarium.exe` をダブルクリック。インストールは要らない

**絵はインストール版と同じ場所**（`%APPDATA%\PaintingsAquarium`）に貯まる。

> **zip 版は「持ち運び版」ではない。** 保存先を exe の隣に変えるのは、
> 持ち運び版の起動の仕組み（`PORTABLE_EXECUTABLE_DIR`）が効いているときだけ。
> zip から出した exe にはそれが無いので、**インストール版と同じ場所**を使う。
> つまり **zip 版とインストール版は絵を共有する**（持ち運び版だけが別）。

### インストール版

1. `PaintingsAquarium-Setup.exe` をコピーして実行する
2. **「WindowsによってPCが保護されました」が出る。**
   これは想定どおり。署名証明書を買っていないため。

   **一番楽なのは、USBメモリ経由でコピーすること。** それだけで警告が出なくなる
   （「よそから来た印」がUSBに落ちるため）。**会場ではこれを使う。**
   出てしまったときの通し方も含めて `docs/警告が出て起動できないとき.md`。
3. インストール先を選ぶ（既定のままでよい）。
   **管理者権限は要らない**（ユーザー単位インストールにしてある）
4. 起動して、写真を入れるフォルダを選ぶ。**設定はこの1回だけ**

### 持ち運び版（USB運用）

1. `PaintingsAquarium-portable.exe` を USB にコピーする
2. 会場PCで直接ダブルクリックする（インストールされない）
3. **USB からそのまま実行すれば、SmartScreen の警告は出ない。**
   コピーした時点で「よそから来た印」が落ちるため
   （`docs/警告が出て起動できないとき.md`）。
   出たときは、その文書の方法2を見る

**絵と設定は exe の隣の `PaintingsAquarium-Data` フォルダに入る。**
だから USB ごと別のPCへ挿せば、絵もそのまま付いてくる。

| | 保存先 |
|---|---|
| インストール版 | `C:\Users\<名前>\AppData\Roaming\PaintingsAquarium\data` |
| 持ち運び版 | exe の隣の `PaintingsAquarium-Data\data` |

保存先はアプリの `S` キーの設定画面にも出る。**迷ったらそこを見る。**

> **2つの版は絵を共有しない。** 同じPCで両方使うと「絵が消えた」ように見える。
> どちらか一方に決めて使うこと。

### 絵ごと引っ越す

上の表のフォルダを丸ごとコピーして、移した先の同じ場所に置けばよい。

ただし **取り込みフォルダの写真さえ残っていれば、入れ直すだけで全部やり直せる**。
これが唯一のバックアップ（要件定義 §5）ので、写真のほうを確実に残すこと。

## 会場での運用

| やること | 頻度 |
|---|---|
| 撮った写真を取り込みフォルダに入れる | 随時（アプリの操作は不要） |
| `S` キーで一覧を開き、不適切な絵を消す | 気づいたとき |
| `F` キーで全画面にして大画面に映す | 起動時に1回 |

**取り込みフォルダを会期中に消さないこと。**

## 未確認のこと

- **Windows 実機でのインストールと起動は確認していない。**
  開発環境が Linux のため、ビルドが通ったことまでしか確かめられていない。
  会場に入れる前に、必ず1台で通しの確認をすること（`docs/リハーサル手順.md`）。
- **持ち運び版を実際に USB から動かしたことはない。**
  保存先を切り替える判定は単体テストで固定してあるが、
  「USBから起動して絵が USB に入る」ところは実機でしか確かめられない。
- しきい値の既定値は実物の写真で合わせていない（D-1）。
  会期前に何枚か試し、設定画面のスライダーで調整すること。
