## 落としてはいけない1点

**台紙の形の条件は、好みではなく実測値。**

照合は**外形の重なりしか見ない**。しかも**4方向＋左右反転＋傾き**を全部試す。
見た目がどれだけ良くても、**形が似ていれば別の生き物として判定される**。
そうなると向き・しなり・動き方が全部ちぐはぐになる。

実際に踏んだもの:

| | 何が起きたか |
|---|---|
| ほそ魚 ↔ サメ | 重なり 0.78。**見分けに失敗したので、ほそ魚を台紙から外した** |
| かぼちゃ ↔ ゆうれい | 丸いおばけにしたら 0.77。幽霊を細長くして回避 |
| 丸いかぼちゃ ↔ ただの四角 | 0.76。**紙まるごとの切り抜きがかぼちゃとして泳ぐ** |
| ステゴ ↔ トリケラ | 0.67 のまま出荷。会場で種類が付かない絵が約半分 |

**だから、絵が出てきたら必ず測る。** 目で見て違えば大丈夫、ではない。

## 手順

### 1. ChatGPT に描いてもらう

指定は `docs/設計-ハロウィンの台紙.md` の「種類ごとの指定」。
各項の「**形の決め手**」は変えないこと。顔・模様・服などの**内側の線は自由**
（外形に影響しないので照合の邪魔にならない）。

全テーマ共通の7か条は `docs/台紙の作り方.md`。特に:

1. 輪郭を1か所も切らない（切れると白が流れ込んで絵が穴だらけになる）
2. 線は黒一色・太く / 3. 内側は白のまま / 4. 文字・枠線を入れない
5. 落ち影・地面の線を入れない / 6. 1枚に1匹・紙の端から十分内側に

### 2. ファイル名を合わせて渡す

```
01_kabocha.png  02_koumori.png  03_yurei.png  04_majo.png  05_franken.png
```

### 3. 測る（この2行だけ）

```bash
python3 tools/prep-templates.py <もらったフォルダ> <出力先>   # 外枠・ラベルを落とす
python3 tools/check-templates.py <出力先>                      # 合否を出す
```

合格の線:

| 見るもの | 合格 |
|---|---|
| 輪郭が閉じているか（塗りつぶし/線） | **2.0 以上** |
| 互いに似ていないか | **0.55 未満** |
| 見分けの試験（傾け・伸ばし） | **全回正解・2位との差 0.20 以上** |
| **「ただの四角」を拾わないか** | 単体テストで見る（`templates.test.ts`） |

最後の1つは `check-templates.py` では出ない。**丸い形の台紙を足したときだけ**
効いてくるので、組み込み時に `npm test` で確認する。

### 4. 落ちたら

落ちた種類の「**形の決め手**」が守られているかを先に見る。
守られていなければ、その条件の文を**プロンプトの先頭近くへ移して**描き直す。
守られていてもなお落ちるなら、**別の種類のほうを動かす**ことも検討する
（かぼちゃがそうだった。幽霊は形を変えずに、かぼちゃの比を変えて逃がした）。

## 並行して進めるときの約束

- **ChatGPT 側は画像だけを作る。** コードとドキュメントはこちらで触る。
  両方からコミットすると、同じ台紙データ（`templates.generated.ts` は自動生成）が
  食い違って、どちらが正しいか分からなくなる。
- **画像はチャットに貼って渡す。** リポジトリへ直接入れない。
  測って合格したものだけを `assets/templates/` に入れる。
- **差し替えたら必ず `npm test` と通し検証まで回す。** 台紙を1枚変えると、
  他の4種との重なりが全部変わる。1枚だけ測って終わりにしない。

## いま開いている宿題

**かぼちゃの描き直し。** `assets/templates/halloween/01_kabocha.png` は
コードで描いた**仮のもの**。生成した丸いかぼちゃが「ただの四角」と 0.76 で
重なったため。描き直しの指定は `docs/設計-ハロウィンの台紙.md` の
「かぼちゃだけ、まだ仮の台紙」の章にある。要点は2つだけ:

- **横に平たく**（本物のかぼちゃの比。比 1.10〜1.15 が実測の最適点）
- **ヘタを長く、横へ曲げる**

平たくしすぎると今度は**幽霊（比 1.31）に近づく**ので、やりすぎないこと。
