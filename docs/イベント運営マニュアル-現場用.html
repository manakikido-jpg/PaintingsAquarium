前日立ち上げる人

アプリとスキャナを整える

当日の朝にやらないでください。失敗したときに直す時間がありません。

アプリを最新にする

設定画面（S キー）→「更新を確認」→「いま入れ替えて再起動する」。 絵と設定は消えません。

スキャナの設定

アプリの操作は0回ですが、スキャナ側は最初に1回だけ設定が要ります。

設定こうする外すとどうなる
保存形式JPG PDFは読めません。書類用スキャナは既定がPDFのことが多い
保存先アプリの取り込みフォルダ スタッフの操作が「毎回コピーする」に増える
解像度150〜300dpi 600dpiは要らない（150も300も取り込み約2.9秒）
ファイル名通し番号。リセットしない 毎回 img001 に戻ると二重取り込みとみなして捨てる。絵が静かに消える
トップLED点ける 影が濃いと、紙の一部が「紙ではない」と判定されて取り込みを断る
フットペダル使う 手で操作すると手や腕が写り込んで影になる
自動切り出し紙のまわりに余白を残す 端ぎりぎりで切ると、絵が写真の縁に触れて丸ごと消えることがある

設定の名前はソフトの版で違うかもしれません。大事なのは JPGで・決まったフォルダへ・通し番号で保存されることの3つだけです。

紙を置く場所を白くする

敷くマットが黒い場合は使わないでください。 白い紙（模造紙・A3のコピー用紙など）を敷きます。

実測

上から撮る方式では、台紙の外側の台まで写ります。台が黒いと、そこが 「紙ではない＝クレヨンと同じ」と判定されて額縁のような塊になります。 前回これで、台紙の見分けが 11/19 → 6/19 まで落ちました。

通しで1枚試す

合格 — 色を塗った紙を1枚スキャンすると、アプリを触らずに数秒で泳ぎ出す。

当日の朝30分

立ち上げる

  1. PC・スキャナ・モニターをつなぐ
  2. アプリを起動する
  3. S キーで設定を開き、テーマ（水族館／ダイナソー）を今日のものにする
  4. 取り込みフォルダが前日のままか確認する
  5. F キーで全画面にする
  6. 試しに1枚スキャンして、泳ぎ出すのを見る
  7. 試した絵を一覧から消す

ここまでで立ち上げは終わりです。あとはスタッフに任せられます。

このページを切り取って、スキャナの横に貼る

スキャンの手順

  1. 台紙を渡す
  2. 描けた紙を受け取る
  3. スキャナの下に、まっすぐ置く
  4. フットペダルを踏む
  5. 紙を返す

渡すときに一言 ——「絵の中を塗ってね」

こうする

  • まっすぐ置く
  • 紙のまわりに余白を空ける
  • 1枚ずつ置く
  • 出ないときは、もう一度スキャンする

これはしない

  • アプリを触る（触りません）
  • 手や腕を紙の上に残す
  • 2枚重ねて置く
  • うまくいかなかった紙を捨てる

2回やっても画面に出ない紙は、取っておいて立ち上げた人に渡してください。 あとで直すための、唯一の手がかりになります。

終わったらその日のうちに

イベントを終える

S キーで設定を開き、「イベントを終える」に会場の名前を入れて 「絵を片付けて次へ」を押します。

その会期の絵と、元のスキャン写真がまとめて日付つきフォルダへ移ります。 消えません。移すだけです。 取り込みフォルダとテーマの設定は残るので、次の会期の朝に選び直すことにはなりません。

pieces/泳いでいた絵（切り抜き済み）
pieces.jsonその台帳
scans/スキャナが撮った元の写真 ← 一番大事

なぜ scans が一番大事か

不具合を調べられるのはこれだけです。プテラノドンが飛ばなかった原因は、 実物の紙が手元に来て初めて分かりました。 合成データでは一度も再現できませんでした。

持ち帰るもの：上のフォルダ（丸ごとバックアップ）／ うまくいかなかった紙の現物／参加人数と気づいたこと。

困ったとき症状から引く

だいたいここに入っています

症状見るところ
1枚も泳がないスキャナの保存形式が PDF になっていませんか。JPG にする
1枚も泳がない保存先が取り込みフォルダですか（S キーで確認できます）
ある紙だけ泳がないもう一度スキャンする。それでも駄目なら紙を取っておく
絵が真っ黒／変な四角が泳ぐ敷いているマットが黒くありませんか。白い紙を敷く
絵の中が透けている影です。トップLEDを点ける／手を紙の上に残さない
絵が縦に潰れて見える紙を寄せすぎです。まわりに余白を空ける
途中から取り込まれないファイル名が img001 に戻る設定になっていませんか
前回の絵が混ざっている「イベントを終える」をやらずに始めています。いまからでもできます
画面がカクつくS →「飾りの多さ」を下げる／「しなりの強さ」を 0 にする

どれにも当てはまらないときは、うまくいかなかった紙を取っておいてください。 紙さえあれば、あとから原因を特定して直せます。

毎回記録する

次の会期の判断を良くするために

  • 会場・日程
  • 参加人数
  • 台紙の消費（種類ごと）
  • 泳いだ絵の枚数
  • うまくいかなかった紙の枚数と、その紙
  • スタッフから出た声／来場者から出た声

「うまくいかなかった紙」は必ず現物で持ち帰ってください。枚数だけでは直せません。
