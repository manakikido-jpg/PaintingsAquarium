# 会場PCの選び方

- 作成: 2026-08-24
- 対象: **会場に置くPCを買う人・借りる人**
- 数字の根拠: `docs/推奨スペック.md`（実測）／判断の分かれ目は `docs/やること.md` T-3

---

## 0. 結論だけ先に

1. **まず手持ちのPCで測る。** 持ち運び版を挿して **S キー**、「いまの表示速度」が
   **30fps 以上**なら買わなくてよい
2. 買うなら **Intel N150 のミニPC（2万〜5万円）** を推す
3. 会場で失敗できない・予備も要る、なら **Ryzen 7 8845HS + Radeon 780M（10万円台）**

**いちばん効くのは「内蔵GPUがあること」と「画面が 1920×1080 であること」。**
CPU の速さでも、同時に泳ぐ絵の枚数でもない。根拠は §2。

---

## 1. 何をするPCか

| | |
|---|---|
| 台数 | **1台**（＋スキャナ1台） |
| 使う人 | 会場スタッフ。**アプリの操作は 0 回**（スキャナの保存先が取り込みフォルダ） |
| 使い方 | 起動しっぱなし。紙を通すと 2〜3秒で絵が泳ぎ出す |
| 通信 | **完全オフライン**。外へ出るのは「更新を確認」を押したときだけ |
| OS | **Windows 64bit 専用**（配布物が Windows 版しかない） |

配るのは2つ。どちらも同じアプリで、絵の置き場所だけが違う。

| ファイル | 入れ方 | 絵の置き場 |
|---|---|---|
| `PaintingsAquarium-Setup.exe` | インストールする（**管理者権限は不要**・ユーザー単位） | PCの中（`AppData`） |
| `PaintingsAquarium-portable.exe` | **入れない。exe を置くだけ** | exe の隣のフォルダ |

> **借り物のPCなら持ち運び版。** USB に入れて挿せば、絵もそのままUSBに残る。
> 会場PCに何も残さずに済む。

## 2. どこが重いのか（買う前に知っておくこと）

実測はすべて `docs/推奨スペック.md`。要点だけ。

### 画面が広いほど重い（画素数にほぼ反比例）

| 画面 | fps（絵24枚・GPU無しの環境） |
|---|---|
| 1280×720 | 17.2 |
| 1920×1080 | 8.9 |
| 2560×1440 | 6.1 |
| 3840×2160 | **2.7** |

**4K のモニタは買わない**か、つないでも 1920×1080 で表示する。
「大きい画面」と「解像度が高い」は別の話で、**必要なのは大きさのほうだけ**。

### 絵の枚数はほとんど効かない

12枚 11.6fps / 24枚 8.9 / 50枚 8.9 / **100枚 7.3**。
つまり **1日100枚集まっても重くならない**。同時に泳ぐ数を減らしても軽くはならないので、
減らす理由があるとすれば「見やすさ」のほう。

### CPU の仕事はもう小さい

以前は水面の揺らぎ模様を毎フレーム計算していて、**1フレーム 26ms** かかっていた
（60fps の予算は 16.7ms なので、GPU をどれだけ積んでも 38fps が上限だった）。
2026-08-24 に**起動時へ焼く**ようにして、この計算は 0 になった（F-348）。

いま毎フレーム CPU が使うのは **絵の動きの計算 0.2ms（100枚でも 1.5ms）**だけ。
**残りは全部「塗る」仕事＝内蔵GPUの担当。**

### メモリ・保存量・起動

| | 実測 |
|---|---|
| メモリ | 552〜856MB（絵100枚で 713MB） |
| 起動 | 最初のコマまで 2〜4.6秒 |
| 絵1枚 | **56〜68KB**（1000枚で 70MB） |
| 取り込み | 1枚 **2.3〜2.5秒**（150dpi でも 300dpi でも、色を塗っても同じ） |

絵は取り込むときに長辺 1200px まで縮めてから保存するので、
**スキャナの解像度を上げても保存量も時間も増えない。**

## 3. まず手持ちで測る（0円）

買う前に、手元の Windows PC で確かめられる。

1. `PaintingsAquarium-portable.exe` を USB かデスクトップに置いて起動
2. **S キー**で設定画面 →「いまの表示速度」を読む
3. 目安

| 表示速度 | 判断 |
|---|---|
| **30fps 以上** | そのPCで足りる。買わなくてよい |
| 20〜30fps | 「背景の強さ」を **0** にする（途中の値は効かない）。それで 30 を超えれば足りる |
| 20fps 未満 | 画面を 1280×720 に落として再確認。それでも足りなければ買い替え |

> 2020年以降のPC（Intel Iris Xe / AMD Radeon Vega 8 以降）なら**届く見込みはある**。
> ただし**実機で測ったことはない**ので、見込みであって保証ではない。

## 4. 買う場合の3案

| | 案1 N150 ミニPC | 案2 Ryzen 780M ミニPC | 案3 中古ビジネス機 |
|---|---|---|---|
| 値段 | **2万〜5万円** | 10万〜13万円 | 1万〜3万円 |
| 内蔵GPU | Intel UHD（N150内蔵） | **Radeon 780M**（内蔵最上位級） | UHD 620/630 |
| メモリ | 16GB のモデルが多い | 16〜32GB | 8GB が多い |
| 足りるか | **足りる見込み**（未実測） | **確実側** | 微妙。0 運用になる可能性 |
| 向く場面 | 通常はこれ | 失敗できない／予備も揃える | 台数を安く揃える |

### 案1: Intel N150 のミニPC（推し）

- 例: Beelink EQ14、MaxMini B4 Turbo、リンクス LN150W-16/256-W11Pro（16GB/256GB・51,599円・在庫切れ）
- **2万円台の16GBモデルもある**。HDMI 2系統・4K60対応・ファンレスの選択肢もある
- 毎フレームの CPU は 1.5ms 以下なので、N150 の CPU 性能で困る場面が無い
- 残るのは 1920×1080 の塗りだけ。**足りるはずだが、実機で測っていない**

### 案2: Ryzen 7 8845HS + Radeon 780M のミニPC

- 例: MINISFORUM UM880 PLUS、GMKtec K8plus（32GB/1TB・127,999円）
- 内蔵GPUとしては最上位クラス。1080p で詰まる要素が見当たらない
- **会場で失敗できないなら、この価格差は保険として妥当**

### 案3: 中古・整備済みのビジネス機

- 例: HP ProDesk 400 G4 DM（i5-8500T・8GB・256GB）、ThinkCentre M シリーズ、
  Dell OptiPlex Micro
- Windows 11 に載せるなら **第8世代以降**を選ぶ
- 内蔵GPU（UHD 620/630）は上2つより明確に弱い。**「背景の強さ 0」で運用する前提**なら安い
- 整備済み品（Renewed 等）は検品と返品期間が付くものを選ぶ

## 5. 共通で必須のところ

| 項目 | 要件 | なぜ |
|---|---|---|
| OS | **Windows 10/11 の 64bit** | 配布物が Windows x64 のみ |
| メモリ | **8GB 以上**（16GB なら余裕） | 実測で最大 856MB。4GB は OS と取り合いになる |
| ストレージ | **SSD**・空き 2GB | eMMC は起動と取り込みが遅い。容量は 70MB/1000枚で足りる |
| 映像出力 | **HDMI**（1920×1080 で使う） | 4K は実測 2.7fps |
| USB | **A 端子 2つ以上** | スキャナ＋予備（USBメモリ・マウス） |
| 音 | **静音かファンレス** | 会場で一日中回る |
| 電源 | AC アダプタの置き場と電源タップ | ミニPCは外付けアダプタ |
| 有線LAN | **不要** | 完全オフラインで動く |

### 避けるもの

- **ARM版 Windows**（Snapdragon 搭載機）… 配布物は x64。動くとしてもエミュレーションで、**未検証**
- **4K前提のモニタ構成**… 実測 2.7fps。大きさが要るなら「大きい 1080p」を選ぶ
- **メモリ 4GB / eMMC のみ**の激安機
- **macOS / Linux**… 配布物が無い

## 6. モニタ

| 項目 | 目安 |
|---|---|
| 解像度 | **1920×1080**。4K は 1080p 表示にする |
| 大きさ | 会場の見やすさで決める（解像度と大きさは別） |
| 端子 | HDMI |
| 縦横比 | 違っても動く。画面の広さに合わせて絵の大きさが決まる |
| 置き方 | 全画面は **F キー**。メニューバーは配布版では最初から出ない |

---

## 7. スキャナ

| 項目 | 要件 | 根拠 |
|---|---|---|
| 用紙 | A4 が通ること | 台紙が A4 |
| 解像度 | **150dpi で十分** | 300dpi にしても取り込み時間（2.3→2.5秒）も保存量も変わらない |
| 形式 | **PNG か JPEG** | **HEIC は読めない**（`docs/やること.md` T-9） |
| 保存先 | **アプリの取り込みフォルダを指定できること** | ここができて初めて「アプリ操作 0 回」になる |
| ADF | あると楽 | まとめて通せる。16枚を一度に置いても 32秒で全部入った |

**紙はまっすぐ置く。** 傾きは ±8度まで吸収するようにしてあるが、
大きく傾くと別の生き物として判定されることがある（`docs/リハーサル手順.md`）。

## 8. 借り物のPCを使うときの注意

- **署名証明書を買っていない**ので、初回起動で SmartScreen の警告が出る
  （「詳細情報」→「実行」）。事前に管理者へ話を通しておく
- インストール版は**ユーザー単位**で入るので管理者権限は要らない。
  それでも入れられないなら**持ち運び版**
- 持ち運び版は**絵が exe の隣に貯まる**。USB ごと持ち帰れば、会場PCに何も残らない
- 設定画面に、いまどちらの版で動いていて絵がどこにあるかが出る

---

## 9. 予備機

会場でPCが1台しか無いと、壊れた時点で展示が止まる。
**同じ USB（持ち運び版＋絵）を別のPCに挿せばそのまま続けられる**ので、
予備は「Windows が動く何か」でよい。案3の中古機を1台足しておくのが安い。

ただし**2つの版は絵を共有しない**（インストール版と持ち運び版で置き場が違う）。
本番は**どちらか一方に統一する**こと。

## 10. 買った直後の受け入れ確認（5分）

1. 持ち運び版を起動する（SmartScreen が出たら「詳細情報」→「実行」）
2. **S キー** →「いまの表示速度」を読む。**30fps 以上**なら合格
   - 足りなければ「背景の強さ」を **0** に（**途中の値では変わらない**）
   - それでも足りなければ画面を 1280×720 に
3. 取り込みフォルダを決める → **スキャナの保存先を同じフォルダにする**
4. 台紙を1枚塗って通し、**2〜3秒で泳ぎ出す**ことを確認
5. 全画面（**F キー**）にして、モニタの端で切れていないか見る
6. 30分ほど放置して、落ちないこと・熱でうるさくならないことを見る

詳しい通し確認は `docs/リハーサル手順.md`。
