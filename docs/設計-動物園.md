# お絵描き動物園

2026-11-08。ぞう・ライオン・キリン・さる・パンダ・しまうまの6種類を追加する。

- 運用は既存と同じ。設定で動物園を1回選び、指定フォルダへスキャンするだけ。毎回の追加操作は0回。
- 明るい草原、木陰と遠景の丘に「どうぶつえん」の入口ゲート、木の柵、左右の小道、動物アイコンの案内板を加える。絵が歩く場所を広く空け、6種とも地面の上を歩く。
- 台紙は太い黒線と白だけの横向きの動物。左向き、全身、足を離し、子どもが塗りやすい形にする。
- A4横の6ページPDF。左上に「お絵描き動物園」、絵は余白を残した70%の大きさ。
- テーマ内で6種を照合し、実際の切り抜き後の形で相互の取り違えを測定する。未判定も動物園の標準サイズで歩かせる。
- 向きは台紙の照合で決め、動物園に魚用の自動回転を適用しない。保存画像の色や線は補正しない。
- 足は付け根より下だけを控えめに交互に動かす。キリンの首やぞうの鼻、顔を波打たせない。
- ローカルの独立したテスト用データで6種の取り込み、向き、足踏み、設定操作を確認して動画を作る。
