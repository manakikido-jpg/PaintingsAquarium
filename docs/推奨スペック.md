# 推奨スペック（会場に置くPC）

- 作成: 2026-08-24
- 対象: **会場に置く1台を選ぶ人／借りる人**

このアプリは **PC 1台＋スキャナ**で動く。完全にオフラインで動き、
外へ通信するのは設定画面の「更新を確認」を押したときだけ（`docs/要件定義.md` §4）。

> **下の fps は、GPU を持たない環境（ソフトウェア描画）での実測。**
> 会場のPCではもっと出るはずだが、**まだ実機で測っていない**（`docs/やること.md` T-3）。
> measured したものと、していないものを混ぜないために、ここでは実測値だけを書く。
> 会場PCに入れたら、**設定画面（S キー）の「いまの表示速度」**を見て確かめること。

---

## 結論

| | 最低 | 推奨 |
|---|---|---|
| OS | Windows 10 64bit | Windows 11 64bit |
| CPU | 4コア | 4コア以上（世代は問わない） |
| **GPU** | **内蔵GPUがあること** | 内蔵GPUで十分 |
| メモリ | 4GB | **8GB** |
| ストレージ | 空き 2GB・SSD | 同左 |
| 画面 | 1280×720 | **1920×1080** |
| ネット | 不要 | 不要（更新のときだけ） |
| スキャナ | A4・150dpi・PNG/JPEG保存 | A4・**ADF付き**（連続で取り込める） |

**いちばん効くのは GPU の有無と画面の広さ**で、CPU の速さやメモリの量ではない。
下の実測がその根拠。

## 実測（この開発環境・**GPU無し**・絵24枚・1920×1080）

### 画面が広いほど重い

| 画面 | fps | メモリ |
|---|---|---|
| 1280×720 | **17.2** | 552MB |
| 1920×1080 | 8.9 | 604MB |
| 2560×1440 | 6.1 | 676MB |
| 3840×2160（4K） | **2.7** | 856MB |

画素の数にほぼ反比例する。**4K のモニタは避ける**か、
つなぐなら 1920×1080 で表示すること（画面の設定で解像度を下げる）。

### 絵の枚数はあまり効かない

| 絵の枚数 | fps |
|---|---|
| 12枚 | 11.6 |
| 24枚 | 8.9 |
| 50枚 | 8.9 |
| 100枚 | 7.3 |

**枚数より画面の広さのほうが効く。** 100枚泳がせても大きくは落ちない。
「同時に泳ぐ数」を減らしても軽くはならないので、**減らす理由は見やすさのほう**。

### 背景を消すと軽くなる（途中の値では変わらない）

絵100枚・1920×1080 での実測:

| 背景の強さ | fps |
|---|---|
| 1.0（既定） | 7.3 |
| 0.5 | 6.8 |
| **0** | **15.0** |

**0 のときだけ軽くなる。** 途中の値は層を薄く描くだけで、描く回数は変わらない。
会場で重いときは、中途半端に下げず **0 にする**。

### メモリ・起動・保存

| | 実測 |
|---|---|
| メモリ（4プロセス合計） | 552〜856MB（絵100枚で 713MB） |
| 起動から最初のコマまで | 4.6秒 |
| 絵1枚の保存量 | **56〜68KB**（線画・塗った絵とも） |
| 配るファイル | インストーラ 81MB／持ち運び版も同程度 |

絵は取り込むときに**長辺 1200px まで縮めて**から保存するので、
スキャナの解像度を上げても保存量は増えない。
**1000枚でも 70MB 程度**。1日100枚を10日続けても収まる。

### 取り込みの速さ（紙を置いてから泳ぎ出すまで）

| 取り込む紙 | 1枚あたり |
|---|---|
| A4 150dpi | **2.3秒** |
| A4 300dpi | 2.4秒 |
| A4 300dpi・色を塗ったもの | 2.5秒 |

**解像度を上げても遅くならない**（縮めてから処理するため）。
16枚をまとめて置いたときは 32秒（1枚あたり 2.0秒）で、順番に処理される。

1日100枚でも、処理に使う時間は合計 4分ほど。**スキャンが追いつかないことはない。**

## 選ぶときに見るところ

### GPU

**「内蔵GPUがある」ことが最重要。** 上の数字はGPUを使わない描画での値で、
アプリは**画面を塗る量で重くなる**（画素数に反比例している）。
ここは GPU がまさに担当する部分なので、内蔵GPUがあれば大きく変わる。
ただし**どれだけ変わるかは実機で測っていない**（T-3）。
別売りのグラフィックボードまでは要らない。

### 画面

- **1920×1080 を推奨。** 4K は画素が4倍で、実測でも 8.9 → 2.7fps まで落ちた
- 大きさは会場の見やすさで決めてよい（解像度と大きさは別の話）
- 縦横比が違っても動く。画面の広さに合わせて絵の大きさが決まる（R-015）

### スキャナ

- A4 が通ればよい。**150dpi で十分**（300dpi にしても取り込み時間も保存量も変わらない）
- **保存先をアプリの「取り込みフォルダ」にできること**が必須。
  これができると、スタッフのアプリ操作が **0回**になる（`CLAUDE.md`）
- 形式は PNG か JPEG。**HEIC は読めない**（`docs/やること.md` T-9）
- ADF（自動で紙を送る機構）があると、まとめて通せるので楽
- **紙はまっすぐ置く。** 傾きは ±8度まで吸収するようにしてあるが、
  大きく傾くと別の生き物として判定されることがある（`docs/リハーサル手順.md`）

### OS

Windows 10 以降の 64bit。配るのは次の2つ（`electron-builder.yml`）。

- `PaintingsAquarium-Setup.exe` … インストール版（ユーザー単位で入る。管理者権限は不要）
- `PaintingsAquarium-portable.exe` … 持ち運び版（インストール不要。exe の隣に絵が入る）

**署名証明書は買っていない**ので、初回起動で SmartScreen の警告が出る
（「詳細情報」→「実行」で進む）。会場PCが借り物のときは、事前に確認しておくこと。

## 会場PCに入れたら、最初にやること

1. アプリを起動し、**S キー**で設定画面を開く
2. 「いまの表示速度」を見る
   - **30fps 以上** … そのままでよい
   - **30fps 未満** … 「背景の強さ」を **0** にする（途中の値では変わらない）
   - それでも足りない … 画面の解像度を 1920×1080（または 1280×720）に下げる
3. 取り込みフォルダを決め、**スキャナの保存先を同じフォルダにする**
4. 紙を1枚通して、2〜3秒で泳ぎ出すことを確認する
5. 詳しい手順は `docs/リハーサル手順.md`
