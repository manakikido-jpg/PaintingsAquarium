# 設計: 生き物ごとの動き

- 作成: 2026-08-18
- 状態: **設計（実装前）**。段取りの1だけ着手済み

## 何をしたいか（依頼そのまま）

| 生き物 | 動き |
|---|---|
| 魚 | 顔の向きに進む。**画面外に出たら反転して戻る**。尾びれを振りながら |
| タコ | **上下に上がり下がりしながら**左右に進む。足は泳ぐように動かす |
| イルカ | ひれをなびかせて泳ぐ。**途中でいきなり跳ねる** |
| サメ | **魚を追いかける**。急に速くなったり遅くなったりする |
| クラゲ | ふわふわ漂う |
| ウミガメ | 画面の中を**S字の曲線**で動く。前足と後ろ足を漕ぐように前後させる |

---

## 前提: いまのアプリは「タコとクラゲ」を区別できない

形だけの判定でできるのは **魚 / 足のある生き物 / 不明** の3つまで
（`src/core/rig.ts` の `detectKind`）。
タコとクラゲ、イルカとサメは、形の性質では分けられない。

**分けられるのは台紙照合**（`src/core/match.ts`）。台紙が6種そろい、
見分けの試験も通っている（スキャナ想定で 48/48・いちばん際どい差 +0.26）。
だが**まだアプリに繋がっていない**。ここを繋ぐのが全部の前提になる。

繋ぐと、おまけが2つ付く。

- **頭と尾が推定でなく確定する。** 台紙ごとに正解を1回書いておけばよい。
  R-030 で入れた「頭が分からない絵はしならせない」制限が、台紙の絵では消える
- 手足の位置も台紙ごとに書ける。タコの足・カメのひれを動かせるようになる

---

## 仕組み

```
スキャン → 切り抜き → 台紙と照合 → 種類（species）を絵に保存
                                    ↓
                            種類ごとの動き＋種類ごとの手足
```

| 部品 | 置き場所 | 中身 |
|---|---|---|
| 台紙の形 | `src/core/templates.generated.ts` | 48升の白黒。**PNGから生成**。実行時に画像を読まない |
| 台紙ごとの正解 | `src/core/templates.ts` | 頭の向き・尾の位置・手足の矩形 |
| 見分け | `src/core/match.ts`（既存） | 4方向×左右反転の8通りで一番よく重なる台紙 |
| 絵に保存 | `Piece.species` | `'fish' \| 'tako' \| 'iruka' \| 'same' \| 'kurage' \| 'umigame'` |

**一致しなかった絵（自由画）は今までどおり。** 会場では台紙を使うが、
自由に描いた絵が入っても壊れないようにしておく。

## 6つの動き

すべて**純粋関数**として `src/core/` に置き、単体テストで固定する（CLAUDE.md）。
画面側は「その関数が返した位置に描く」だけにする。

| 生き物 | 進み方 | 手足・ひれ |
|---|---|---|
| 魚 | 頭の向きへ一定速度。**画面の外へ1体ぶん出てから反転**して戻る | 尾びれを振る（既存 F-320 / F-321） |
| タコ | 左右へ進みつつ、縦にゆっくり大きく上下（周期4〜6秒） | 8本の足を**縮めて伸ばす**拍（進む向きと逆に遅れて動く） |
| イルカ | 普段は魚と同じ。**8〜15秒に1回、放物線で跳ねる**（画面上端で体が半分出る） | 尾びれ＋胸びれ。跳ねる間は体を弧に反らせる |
| サメ | **一番近い魚**へ向きを寄せる。速さは 0.6倍〜2.2倍を不規則に切り替える | 尾びれを大きく振る（速いほど速く） |
| クラゲ | ほぼ止まって上下にふわふわ。横はごくゆっくり流される | かさの拍に**遅れて**触手が伸び縮み |
| ウミガメ | 横に進みながら縦にサイン波（**S字**）。向きは進行方向に合わせる | 前足・後ろ足を前後に漕ぐ（前足が先、後ろ足が半拍遅れ） |

### 手足の動かし方

**既存のひれの仕組みをそのまま使う。** 元画像の一部を切り出し、
付け根を軸に回して描く（`Aquarium.tsx` のひれ処理）。
`clip()` は使わない（R-022: 3匹で 0.3fps になった）。

台紙ごとに「どこが手足か」を矩形で書いておく。推定しないので外れない。

```ts
// 例: ウミガメ（台紙の中の割合。左上が 0,0）
limbs: [
  { id: 'front-left',  box: { x: 0.06, y: 0.18, w: 0.30, h: 0.26 }, pivot: { x: 0.34, y: 0.34 } },
  ...
]
```

## 速さの予算

いまの実測は **12.6fps**（開発環境・GPU無効・絵11枚）。会場の実機では未測定。

追加で増える描画は、1匹あたり最大で

| 生き物 | 増える `drawImage` |
|---|---|
| タコ | 足8本 → **+8** |
| ウミガメ | 足4本 → **+4** |
| クラゲ | 触手はまとめて1枚 → +1 |
| その他 | 0〜2 |

50匹すべてがタコだと **+400回／フレーム**。これは危ない。
**手足の本数は「1匹あたり4本まで」に丸める**（タコは足を2本ずつまとめて4組）。
入れたら必ず実測し、重ければ「ひれの動き」スライダーで切れるようにする。

## やらないこと

- 当たり判定（ぶつかって跳ね返る）
- 群れ（互いに向きを合わせる）
- サメが魚を**食べる**。追いつく手前で減速して離れる
- 音

---

## 決めてほしいこと（推奨つき）

- **D-1 サメが追う魚がいないとき** — 推奨: **普通に泳ぐ**。魚が入ってきたら追い始める
- **D-2 サメは追いつくか** — 推奨: **追いつかない**。少し手前で離れる。
  会場で「食べられた」に見えると、その絵を描いた子が悲しむ
- **D-3 イルカが跳ねる頻度と高さ** — 推奨: **8〜15秒に1回・画面上端で体が半分出る**
- **D-4 台紙に一致しない絵（自由画）** — 推奨: **今までどおり**（魚の動き。頭が分かるときだけ尾を振る）
