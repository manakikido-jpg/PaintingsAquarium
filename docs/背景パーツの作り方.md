# 背景パーツの作り方（画像生成）

- 作成: 2026-08-18
- 目的: 背景の岩・サンゴを**画像として作り、アプリに同梱する**
- 背景: 図形とグラデーションで描く方式は見た目の上限が低く、「安っぽい」の原因になっていた（R-025）

---

## なぜ画像にするか

| | 図形で描く（いまの方式） | 画像を貼る |
|---|---|---|
| 見た目 | 多角形とグラデーションに見える | **デザインされた絵に見える** |
| 速度 | 1個につき5工程（縁・影・塗り・切り抜き・光） | **`drawImage` 1回** |
| オフライン | 保てる | **保てる**（作るのは開発時の1回だけ） |
| 変化 | 乱数で無限に作れる | 枚数ぶん。大きさ・反転・色味で散らす |

**オフラインは壊れない。** 生成するのは開発時で、できた画像を同梱する。
実行時には何も通信しない（要件定義 §4）。

---

## 出力の仕様（ここは必ず守る）

| | |
|---|---|
| 形式 | **PNG・背景は完全に透明** |
| 大きさ | 長辺 1000〜1500px |
| 向き | **地面に接する側を下端**に置く。宙に浮かせない |
| 余白 | 絵の周りの透明な余白は**できるだけ詰める**（こちらで詰め直すが、少ないほど正確） |
| 影 | **落ち影は描かない。** 接地の影はアプリ側で付ける（付いていると二重になる） |
| 枚数 | 岩 6〜10 ／ サンゴ 4〜6 ／ 海藻 2〜3 |

ファイル名は `rock-01.png` `coral-01.png` `weed-01.png` のように連番で。

---

## 共通のスタイル指定

**すべてのプロンプトの先頭に付ける。** これが揃っていないと、並べたときに
別々の絵から切り抜いてきたように見える。

```
flat vector illustration, stylized and deformed (not realistic),
bold saturated pop colors, simple clean shapes, soft smooth shading,
thick smooth silhouette, no outline stroke, no texture detail,
children's museum installation art style, isolated object,
transparent background, centered, object sits flat on the ground at the bottom edge
```

日本語で指定する場合:

```
フラットなベクター風イラスト、デフォルメされた形（写実ではない）、
彩度の高いポップな色、単純で滑らかな形、やわらかいグラデーション、
輪郭線なし、質感の描き込みなし、子ども向け展示のアート風、
単体のオブジェクト、背景は透明、下端が地面に接している
```

## ネガティブ（除外する指定）

```
photorealistic, realistic texture, noise, grain, drop shadow, cast shadow,
background, seabed, water, bubbles, fish, text, watermark, frame, border,
dark colors, muted colors, thin spiky shapes
```

**`drop shadow` と `cast shadow` を必ず除外する。** 影はアプリ側で付けるため。
**`thin spiky shapes` も除外する。** 細く尖った形が並ぶと読めない模様になる（R-024）。

## 部品ごとのプロンプト

### 岩（いちばん重要・数を多く）

色を変えて 6〜10 枚。`{色}` を差し替えて回す。

```
[共通のスタイル指定]
a large smooth rounded underwater boulder, {色} color,
wide and low, asymmetric organic silhouette, one solid bright color
with soft gradient from lighter top to deeper bottom
```

`{色}` に入れる語（参考画像から）:
`vivid orange` / `hot magenta pink` / `bright turquoise` / `warm yellow` /
`vivid cobalt blue` / `fresh yellow green`

> **横に長く、低い形**にすること。縦に細長い岩は「柱」に見えて別物になる。
> 左右対称にしないこと（対称だと「ドーム」に見える）。

### サンゴ（枝）

```
[共通のスタイル指定]
a chunky branching coral, {色} color, thick rounded branches,
few branches, smooth rounded tips, no thin spikes
```

`{色}`: `coral pink` / `bright turquoise` / `vivid purple` / `warm orange`

> **枝を太く、数を少なく。** 細い枝がたくさんあると棘の束に見える（R-024）。

### サンゴ（塊）

```
[共通のスタイル指定]
a rounded brain coral mound, {色} color, smooth lobed surface,
wide and low, soft rounded bumps
```

### 海藻（要るなら・少数）

```
[共通のスタイル指定]
a small clump of wide soft seaweed blades, {色} color,
broad rounded leaves, gently curved, not thin, not spiky
```

> **葉を幅広く。** 細い葉は棘に見える。要らなければ作らなくてよい。

## 渡してもらったあとの流れ

1. `assets/decor/` に置く
2. 一覧（どの画像がどの種類か・地面に接する位置）を作る
3. 大きさ・左右反転・奥行きによる色の薄め・重なり順は**アプリ側で散らす**ので、
   同じ画像が何度出ても別物に見える

## 確認すること

**生成した画像を、商用の公開展示で使ってよいか**を、使った生成サービスの
利用規約で確認しておくこと。多くは可だが、サービスによって条件が違う。
