# お絵描き動物園：発注用素材

2026-11-12。現在の6種類の原画と印刷台紙を、制作依頼先へ渡せるZIPにまとめた。

- [素材一式 ZIP](zoo-order-materials-2026-11-12.zip)
- [6種一覧・発注ガイド PDF](zoo-order-guide-2026-11-12.pdf)

ZIPには原寸PNG6枚、A4横6ページの台紙PDF、背景と透過の雲、動きのGIF、発注ガイドPDFとUTF-8の説明文、SHA-256の一覧を同梱。元のPNGと台紙PDFはバイト単位で同一。ガイド内の一覧表示だけを縮小し、原寸素材は変更していない。AI/SVG/PSDの編集原稿は含まれない。

新作の絵へ変更したら、アプリ側の種類判定データと足・しっぽの位置を更新して再検証する。アプリ本体への変更や会場への配布は行っていない。

再生成は `python tools/package-zoo-order.py --date 2026-11-12`。PyMuPDF・fontTools・PillowとNoto Sans CJK JPを使用する。ZIPの展開、全ファイルのハッシュ、6枚の原寸PNG、6ページのA4横PDF、3ページのガイド、日本語描画と文字抽出を検査済み。
